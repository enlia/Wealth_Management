> **一句话**：财务因子研究此前用**未复权价**算收益，污染量达 **5~17pp/年**，
> 大于本项目声称的任何因子收益。修复后，**「bp 是唯一三段净收益全正的因子」这个结论被推翻**。

## 一、缺陷是什么

`run_financial_study.py` 取价格面板时用了 `field="close"`（**未复权**），
而这个面板直接喂给 alphalens 的 `prices` 参数 —— 用来算前瞻收益、IC、多空组合收益。

未复权价在除权日有**向下的假跳空**。被当成真实跌幅。

### 实测污染量（全市场 5,606 只等权口径，未复权 − 前复权）

| 年份 | 未复权年化 | 前复权年化 | 偏差 |
|---|---|---|---|
| 2016 | −1.08% | +15.72% | **−16.80pp** |
| 2017 | −16.15% | −7.18% | −8.97pp |
| 2019 | +41.06% | +51.86% | −10.80pp |
| 2021 | +31.64% | +39.51% | −7.87pp |
| 2025 | +63.53% | +70.49% | −6.97pp |
| 2022~2026 每年 | — | — | −5.1 ~ −7.7pp |

**这个量级大于本项目此前声称的任何因子收益**（最高的 ep 也只有 +6.1%）。
换句话说：之前算出来的因子收益分不清是「因子有效」还是「除权缺口」。

### 影响范围

全项目扫描后，**6 个研究脚本**存在同一问题：
`run_financial_study` / `compare_synthesis` / `expand_factor_library` /
`head_to_head_vs_qlib` / `holding_period_test` / `optimize_turnover`

⇒ `runtime/financial/` 下 **bp / ep / roe / profit_yoy / revenue_yoy /
gross_margin / cf_quality 全部 7 个因子的 IC 与多空收益不可信**。

## 二、修法：两种价格口径必须分开

关键点：**一个价格面板无法同时充当两个角色**。

| 角色 | 必须用| 原因 |
|---|---|---|
| 算 PB / PE / EP | **未复权 `close`** | `bps`/`eps` 是财报里**实际披露**的每股数字，与未复权价同口径 |
| 算前瞻收益 / IC / 回测 | **前复权 `close_adj`** | 未复权价在除权日有假跳空 |

独立验证 PB 口径（茅台 2024-03-31，`ratio = 0.9088≠ 1`）：

```
close     = 1704.00   bps = 190.84  →  PB = 8.929
close_adj = 1548.56   bps = 190.84  →  PB = 8.114
```
两个口径差 10.3%。与真实市净率同口径的是 **8.929**（未复权）。

### 变更清单

| 文件 | 变更 |
|---|---|
| `src/factor_lab/data/factor_prices.py` | **新增**。`load_factor_prices()` 返回 `(raw, adj)` 具名对；索引不一致时抛错 |
| `src/factor_lab/data/sqlite_source.py` | `load_prices` 的 `field` **取消默认值**（见下） |
| 6 个研究脚本 | 显式双口径：PB 用 `px_raw`，收益用 `prices`(adj) |
| `tests/conftest.py` | **新增**。`require_db` 标记，让依赖本机数据库的测试在 CI 上 skip |
| `tests/test_adjusted_price_guard.py` | **重写**。79 项守卫（见下） |

### 为什么把 `field` 的默认值删掉

首版修复把默认值从 `close` 改成 `close_adj`，但子 agent review 指出：
**保留默认值等于把设计缺陷藏进 API**。

review 实测三种绕过全部通过（正则守卫是橡皮章）：

```
变异 2：`field=_F`（变量传入）        → 42 passed❌ 没抓到
变异 3：`load_prices(c, START, END, "close")` → 42 passed  ❌ 没抓到
```

修法是**取消默认值**：漏写口径现在抛 `TypeError`。
TypeError 是吵的，静默的 −16.80pp 不是。**门禁代替不了设计**。

## 三、修复后因子结论：**bp 被推翻**

### 全样本（行业 + 市值中性化口径）

| 因子 | IC 均值 | ICIR | 多空年化毛 | 多空年化净 |
|---|---|---|---|---|
| bp | +0.0243 | 0.331 | +9.34% | **−0.37%** ← 修复前 +3.22% |
| ep | +0.0193 | 0.349 | +12.99% | +4.14% ← 修复前 +6.13% |
| roe | +0.0092 | 0.168 | +9.60% | +4.35% ← 修复前 +1.76% |

### 三段子区间稳定性（多空年化净收益）

**bp —— 此前「三段全正」，实际第一段是 −7.17%：**

| 区间 | 修复前 | 修复后 | 变化 |
|---|---|---|---|
| 2016-2018 | **+1.03%** | **−7.17%** | **−8.20pp** |
| 2019-2022 | +7.06% | +3.94% | −3.12pp |
| 2023-2026 | +2.22% | +0.81% | −1.42pp |

**ep —— 首段仍强，后两段仍失效（结论未变，数值下调）：**

| 区间 | 修复前 | 修复后 |
|---|---|---|
| 2016-2018 | +33.04% | +23.29% |
| 2019-2022 | +0.30% | **−0.40%** |
| 2023-2026 | −5.01% | −4.04% |

**roe —— 首段极强，后两段为负（结论未变，数值改善）：**

| 区间 | 修复前 | 修复后 |
|---|---|---|
| 2016-2018 | +30.66% | +30.98% |
| 2019-2022 | −6.42% | −3.07% |
| 2023-2026 | −9.87% | −6.66% |

### 判读

1. **bp 从「唯一三段全正」变成「三段里有两段勉强为正、第一段为负」。**
   按项目判据（胜率 ≥60% / 超额中位数 >0 / 最差窗口 >−5%）**不通过**。
2. **三个因子的共同形态：2016-2018 极强，2019 后失效。**
   这不是复权口径造成的（修复前后同向），说明是**市场风格变化**，
   2016-2018 的价值/质量溢价在之后没有延续。
3. **IC 与净收益再次背离**：bp 的 ICIR 最高（0.331），但净收益 −0.37%。
   与价量因子那次「高IC = 高换手 = 负收益」是同一个病 ——
   **IC 只说明单调相关性，不说明能赚到手**。

## 四、副产品发现：`close_adj` 是前复权，不是后复权

子agent review 发现，项目里 **86 处注释**把 `close_adj` 写成「后复权」。

实测 `adj / close` 比值：

```
sh600519ratio 首日 0.793056  →  末日 1.000000
sz000001  ratio 首日 0.605294  →  末日 1.000000
```

末日恒为 1.000000 ⇒ **最新一天close_adj ≡ 未复权价** ⇒ **前复权（qfq）**。
（后复权应首日 = 1、末日 > 1。）

根因在 `backfill_delisted.py:288`：
`close_adj = close × adj_factor / norm`，`norm` 取**最新交易日**的因子。

### 🔴 前复权的代价：历史值不可复现

**每新增一次分红送转，全部历史前复权价都会整体重算。**
⇒ 今天重跑同一个脚本，2016 年的数字会和三个月前不一样。

⇒ **引用 runtime/ 下任何历史结论时，必须同时引用数据版本戳。**

已全项目纠正 86 处表述，并在 `adjust.py` 顶部写明公式与这个代价。

## 五、另一处被推翻的注释

`run_financial_study.py` 原注释：

> 用于 log 市值中性化时常数倍会被回归截距吸收，故结果一致（实测残差差异 6.66e-16）

**实测推翻**：`log(cap_adj) − log(cap_raw) = log(复权因子)`，
而复权因子**逐股逐日不同**，不是全样本一个常数。

```
逐日截面 std(log adj − log raw)：中位 0.0168、最大 0.0276、极差 0.05
```

⇒ 截距吸收不成立。那句 6.66e-16 来自「亿元 vs 万元」的单位换算差（**真**常数倍），
被错误推广到「复权口径」这个完全不同的场景。

**这是 CODE_TRUST P23 的典型**：用一次验证的结论覆盖了一个新场景。

修法：删除错误论证，改为「接受未复权市值」，并给出**保序**层面的理由
（log 保序 ⇒ 中性化用的截面排序不变）。明确区分「数值一致」与「排序一致」两种主张。

## 六、守卫：为什么这次能拦住

| 守卫 | 拦过什么真错 | 状态 |
|---|---|---|
| `field` 无默认值 | 6 个脚本漏写口径 | 有效（API 层消除） |
| AST 扫 `load_prices(..., "close")` | 位置参数/关键字参数传入 | 有效，**经注入验证** |
| 语法门禁 `compile()` | 3 个脚本 SyntaxError 而 pytest 全绿 | 有效，**经注入验证** |
| 双口径接口一致性 | raw/adj 索引错位 | 有效 |

⚠️ **首版守卫是橡皮章**：review 实测位置参数绕过它照样通过，
且 3 个脚本处于 SyntaxError 状态时它报 `hits=[]` 完全无感。
**重写为 AST + 语法检查后才真正有效。**

### 真实事故记录

批量替换价格口径时，`{ind}` 缩进占位符被当成内容写进了 3 个脚本，
造成 SyntaxError，**而 `pytest` 报 350 passed 全绿** ——
因为测试从不import `research/` 下的脚本。

⇒ 「测试全绿」不等于「代码能跑」。已补语法门禁。

## 八、口径声明

- **年化口径**：自然日 `365.25`；未使用 `len/252`（252 是美股口径，A 股 243~245）。
- **成本假设**：往返 20bp（买入 7.5bp + 卖出 12.5bp），按换手率线性摊。
- **基准**：本节的多空收益是 **Q5 − Q1** 的**多空组合**，不是单边多头。
  A 股散户无法做空，**不可直接用于选股**。
- **方向**：所有「多空年化」均为 **Q5（因子值最高）− Q1（因子值最低）**，
  即**因子值越高越做多**。
- **样本**：全市场 A 股 4,925 只（有财务数据者）× 2,551 交易日（2016-01-01 ~ 2026-09-30）。
- **中性化**：行业（申万一级）+ log 市值，逐日横截面回归。
- **幸存者偏差**：已补 15 只 2016 后上市后退市标的，敞口 0.268% → 0。
- **多重比较**：本项目已扫描 7 个财务因子 + 11 个价量因子，
  18 个因子里「看起来有效」的会有若干纯属偶然，未做多重比较校正。
