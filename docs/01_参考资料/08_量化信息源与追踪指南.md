## 1. A. 论文预印本（免费、最新）

### A1. arXiv q-fin（Quantitative Finance）—— 最高优先级

| 项目 | 实测结果 |
|---|---|
| 入口 | https://arxiv.org/list/q-fin/recent |
| 状态 | **活跃**。2026-10-02 批次 25 条；2026-10-01 批次 10 条；2026-09-30 批次 17 条 |
| 更新频率 | arXiv 惯例：**新提交通常每晚公告一次**（new submissions are announced nightly）。`/recent` 页按公告日滚动，非实时 |
| 每日条目量级 | 第三方 RSS 监控站 feeder.co 记录：近 7 天 140 条，约每天 18 次更新（含 cross-list 与 replace） |
| RSS | ✅ `https://rss.arxiv.org/rss/q-fin`（已实测有效） |
| 成本 | 完全免费，无需注册 |

| `q-fin.TR` | Trading and Market Microstructure | ★★★★ 交易成本、冲击成本 |

**订阅方法（官方原文，注意必须是纯 ASCII 邮件）**：
```
To: q-fin@arxiv.org
Subject: subscribe
你的名字

add PM
add ST
```
取消用 `Subject: cancel`。注意：邮件必须纯 ASCII 文本，主题里带 UTF-8 字符会被系统忽略。
官方说明：https://arxiv.org/help/subscribe

**实操建议**：q-fin 每天十几条，PM+ST 合起来仍偏多。建议**只订 PM 和 ST**，其余按需用 RSS 拉。arXiv 无"关键词过滤"机制，所以宁可少订两个分类。

⚠️ **两个必须知道的坑**：
1. **arXiv 是 preprint，不是同行评审**。2025-12 有一篇因子拥挤度论文（arXiv:2512.11913）被作者**主动撤稿（withdrawn）**，理由是"第 5-7 节的实证验证不足以支撑全文的普适性主张"。这说明 arXiv 上"看起来很完整"的论文也可能是自嗨。用 arXiv 定选题，用正式期刊核实结论。
2. **q-fin.PM / q-fin.ST 里"因子"绝大多数是美股**。A股验证要自己补（见第 4 节）。

## 2. B. 学术期刊（权威但付费）

### B1. 三大英文顶刊

| 期刊 | 出版方 | 开放获取情况 | 实用路径 |
|---|---|---|---|
| The Journal of Finance | Wiley | 无 OA | ❗**不要直接订**。用 SSRN / NBER 找预印本；用 AEA（American Economic Association）的 Data + Code 页面拿作者自存档 |
| Review of Financial Studies | Oxford University Press | 无 OA | 同上； EconPapers（econpapers.repec.org）可免费看摘要，且常标注 hdl.handle.net 的可下载版本 |
| Journal of Financial Economics | Elsevier | 无 OA | 同上；作者主页/机构库常有 postprint |

**✅ 核心技巧（免费看顶刊论文的三条路）**：
1. **SSRN**：先搜作者名 + 标题，命中率极高（本次核实的多篇论文都有 SSRN 版）。
2. **EconPapers / RePEc**（econpapers.repec.org）：**免费看摘要，且它会告诉你是否有可下载版本**。本次核实中，正是 EconPapers 让我确认了 Arnott et al. "Factor Momentum" 的 RFS 2023 卷期页码。
3. **作者主页 / NBER / 机构库**：很多顶刊作者会把 final version 挂在自己主页。

❗**重要提醒：本次核实发现大量"论文搬运"网站（quantdecoded.com、ledgertouch.com、thequant.space、socratopia.app 等），它们会给出看似精确的数字和文献，但部分内容存在**引用错误、甚至疑似 AI 生成的伪引文**。本次核实中就发现 quantdecoded 一篇文章把"Factor Momentum Everywhere"归给 Kelly & Xiu(2023)，而**实际作者是 Gupta & Kelly (2019, JPM)**。**这类站点的数字一律回原始论文核对**。

### B2. 中文顶刊

- 《金融研究》《管理世界》：均为付费订阅，机构才能读全。
- **本节的替代品，强烈推荐**：**《管理世界》官网（qjem.cn）会免费发布旗下论文的英文摘要与要点**。本次核实中，正是通过 qjem.cn 确认了 Management Science 那篇 A 股异象复现论文在《经济管理学刊》编委年度盘点中的条目与核心数字。
  - http://www.qjem.cn/CN/news/news19.shtml
- **CNKI 替代**：很多中文期刊论文会在作者所在机构官网挂 PDF 免费版；用 Google Scholar 的"所有版本"（All versions）功能搜标题，比逐个付费下载高效。

## 4. D. 复现与开源（最重要的实操渠道）

### D1. qlib 的 Alpha158 / Alpha360 —— 现状核实（重要修正）

| 项目 | 实测结果 |
|---|---|
| 仓库 | https://github.com/microsoft/qlib |
| 因子集 | **只有 Alpha158 和 Alpha360 两套**，均支持 A 股（China Market）与美股。**没有** AlphaPortfolio、Alpha101、Alpha102 等更新命名因子集 |
| 因子集实现 | `qlib/contrib/data/handler.py`；文档 https://qlib.readthedocs.io/en/latest/advanced/alpha.html |
| **最新正式版** | ⚠️ **README 页面显示 v0.9.0（2022-12-09）**，但 **PyPI 上 pyqlib 实际最新为 0.9.7**。**README 滞后于发布**，请以 PyPI 为准 |
| 仓库活跃度 | 2,068 commits；主分支最近提交 **2026-09-16**；`qlib/` 目录最近提交 2026-07-23 —— **仓库活跃，发布节奏偏慢**（正式 release 少，CI 提交多） |
| Python 支持 | 3.8 – 3.12 |
| 数据 | ⚠️ A 股数据由 qlib 官方托管的公开数据源获取，覆盖范围与质量不如 Wind/聚宽；官方数据有更新滞后，实盘研究建议自备数据 |

**结论：qlib 的因子集本身基本没更新**（还是 Alpha158/Alpha360，最新 release 0.9.7），但**模型库在持续扩充**（LSTM/GRU/ALSTM/GATs/SFM/TabNet/Transformer/TCN/DoubleEnsemble/TCTS/Localformer/TRA/ADARNN/ADD/HIST/IGMTF/KRNN/Sandwich，以及 Rolling Retraining、DDG-DA 等动态适配方法）。

**🚨 必读：alphalens 最容易让你亏钱的一个默认值**

这不是工具 bug，是**默认约定**。`compute_forward_returns` 内部是 `pct_change(period).shift(-period)`：对 date t 观测到的因子，1 日期前瞻收益是 **P[t+1]/P[t] − 1**，即**从 t 收盘价本身开始计息，而 alphalens 不会替你把因子滞后一期**。

如果你的因子来自 t 日收盘价（绝大多数收盘价指标都是），那么 alphalens 报的 1 日收益在现实中**你根本吃不到**——因为只有在你产生信号的那一刻以那个价格成交才做得到。
两种修正方式：
```python
# 方式一：自己把因子滞后一期（推荐）
factor = factor.groupby(level=1).shift(1)
# 方式二：传入以次日开盘价为锚的 prices
```
**另外**：`cumulative_returns=True` 是默认值，此时相邻行共享 p−1 天的价格路径，**重叠收益会虚高均值分位差的 t 统计量**。做统计推断时应设 `cumulative_returns=False`。max_loss=0.35 抛 MaxLossExceededError 通常说明对齐真的错了，**别直接调高阈值**。
