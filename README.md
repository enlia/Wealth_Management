## 最重要的五条结论

### 1. 斐波那契回撤：已被严格检验为不支持

| 检验 | 结果 |
|---|---|
| ESWA (2022) 三市场 logistic 斜率 | **全部不显著** |
| vs 随机非斐波那契基准 | **跑输** |
| vs 买入持有指数 | **跑输** |

本工作区实证（1,273 样本）独立得到相同方向：81 个失效案例 **100% 都越过 0.618 才掉头**（反弹进度中位数 82.4%），在 0.618 买入持 40 日收益中位数 **−3.68%**、胜率 41.8%。

**决定成败的是"能否创新高"（HH），不是"到没到 0.618"。**

### 2. 你读到的因子夏普都偏高

**McLean & Pontiff (2016, JF)**：97 个预测变量，**发表后收益平均降 58%**，其中 32% 直接归因于他人开始交易它。

→ 含义：调参本身就在贡献衰减。**你正在做的事，也是被研究对象之一。**

### 3. A 股动量"消失"之谜

**T+1 制度**把"卖出一个日内看涨期权"嵌入收盘价 → 日内动量与隔夜动量**方向相反、相互抵消**。高波动期动量策略平均 **−1.33%**，低波动期 **+1.27%**。

→ 文献冲突的根源是**未设冷却期**：**必须跳过最近 1 个月**。

### 4. 技术规则的样本外衰减

Brock(1992) 发现道指技术规则显著 → Sullivan(1999) 样本外 p=0.15 → **Bajgrowicz & Scaillet(2012) 样本期延长 25 年后优势完全归零**，并称 Brock 是"通过大规模数据窥探事后发现的统计异常"。

### 5. 量化不需要显卡

全市场 9,570 只 × 4 因子，本机 16 线程 **8.6 秒**、内存 < 1 MB。硬件零门槛。
