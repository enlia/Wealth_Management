# 05 · 知识体系地图：从零到能独立做量化研究

> **读者画像**：A 股个人投资者，有形态识别基础（技术分析），**最大短板是风险管理能力**。
> **本文件的设计逻辑**：不按"书单顺序"排，按**能力依赖顺序**排。每一阶段有明确的**产出物**（能拿出手的东西），没有产出物就不算完成。
> **核实日期**：2026-10

---

## 0. 先明确一件事：你的路径不是"从零开始"

你已经有的东西，必须先承认并利用：

| 你已具备 | 含义 | 在路径中的位置 |
|---|---|---|
| **形态识别基础** | 你已经能读图、识别形态。**这已经越过了"零基础"这道门槛** —— 很多人卡在这里 | 阶段 1 的起点，不需要重学技术分析 |
| **形态识别= 主观判断** | 形态识别的本质是**模式匹配**，它有价值（可能真的存在某种可预测性），但它**天然无法回答三个致命问题**：①这个形态的期望收益是多少？②我该下多大注？③它是不是我事后找出来的？ | **这三个问题就是你的学习目标。** 整条路径都在回答它们 |
| **实战经验** | 你见过真实的盈亏 | 阶段 4 的起点（比纯理论读者快很多） |

**所以你的核心任务不是"学更多技术分析"，而是三件事**：
1. **把主观判断变成可测量的数字**（形态 → 量化信号 → IC）
2. **学会管住仓位**（这是你唯一真正缺的技能）
3. **学会怀疑自己**（统计检验、过拟合控制 —— 这是前两者的护栏）

### 阶段 2 ★★ 风险度量与仓位管理（**你的核心缺口，4–8 周，投入最多**）

**这是整条路径最重要、也是大多数个人投资者永远跳过的阶段。**

| | |
|---|---|
| **目标** | 掌握三件事：①如何量化"这笔交易的风险" ②如何用它决定仓位 ③如何组合多个头寸 |
| **核心材料（按顺序）** | ① **《海龟交易法则》第 7 章「如何衡量风险」+ 第 8 章「风险与资金管理」** —— 先读这两章，**不要从头读到尾**<br>② **《海龟交易法则》第 11 章「历史测试的谎言」+ 第 12 章「历史测试的统计学基础」** —— 回测陷阱的入门版<br>③ **Carver《Systematic Trading》第一部分（Theory）** —— 特别是 "Sleep at night: Position size is as important as position sign"、"The three sins: Overfitting / Overtrading / Overbetting"、"Position sizing"、"The good, the bad and the ugly of systematic trading"<br>④ **Grinold & Kahn 的基本法则**：IR ≈ TC × IC × √BR<br>⑤ （可选）Cartea/Jaimungal/Penalva《Algorithmic and High-Frequency Trading》第 5 章随机最优控制与停止 —— **只读第 5 章，不要通读** |
| **产出物** | **一份《交易规则文档》，必须包含以下 7 条，每条都要有具体数字：**<br>① **单笔最大风险** = 总资金的 **?**%（建议从 0.5%–1% 起步，这是可执行起点，不是最优解）<br>② **头寸规模公式**：仓位 = (账户 × 单笔风险%) ÷ (ATR × 止损倍数)<br>③ **止损位置**：用什么客观规则（波动率/结构/整数关口）—— **必须是事前规则，不能是"感觉不对就卖"**<br>④ **总仓位上限** = 账户的 **?**%（**这一条比单笔止损更重要**）<br>⑤ **最大回撤熔断线**：账户从峰值回撤到 **?**% 时强制降仓<br>⑥ **相关性上限**：同一行业/同一逻辑的头寸合计不超过 **?**%<br>⑦ **成本模型**：单边手续费 + 印花税 + **预估滑点**（A股：卖出印花税 0.05%，佣金约 0.01%–0.03%，滑点按成交额的一定比例估） |
| **通过标准** | **能做到两件事才算过**：<br>① 对任意一笔新交易，能在**3 分钟内**算出精确到手的股数，且**能说清这个数字来自规则的哪一条**<br>② **把过去 20 笔交易用这套规则重新算一遍仓位**，看结果差异 —— 差异会让你不舒服，那正是价值所在 |
| **时间** | 4–8 周。这是整个路径里**唯一值得慢下来**的阶段 |

#### 阶段 2 的核心思想（必须内化的 5 句话）

1. **头寸规模与头寸方向同等重要。**（Carver）大多数人的亏损不是判断错，是仓位错。
2. **风险要按波动率标准化，不是按金额。** 两只股票，一个日均波动 2%、一个 5%，前者仓位应是后者的 2.5 倍。
3. **分散只降低波动，不降低"归零风险"。** 500 只都押同一个逻辑，仍是一次下注。
4. **换手率和成本是隐形的稳定支出。** A股单边成本约 0.1%–0.2%，一年换手 10 次就是 **1%–2%** 的确定损耗。**你的策略必须先跑赢成本再谈盈利。**
5. **回测的漂亮结果通常意味着过拟合，不是意味着找到了圣杯。** 见阶段 3。

### 阶段 3 · 统计与概率（**最容易被跳过，但对"防骗"最关键**，6–10 周）

| | |
|---|---|
| **目标** | 能回答一个问题：**"我这个策略的收益，是本事还是运气？"** |
| **核心材料** | ① **《金融机器学习》(Advances in Financial Machine Learning)** —— **不要通读！只读**：第 7 章（金融交叉验证）、第 11 章（回测的风险）、第 13 章（合成数据回测）、第 14 章（回测统计量）<br>② **López de Prado, "The Deflated Sharpe Ratio" (2014)** —— 第 11 章的核心论文，**先读论文再读章节**<br>③ **《Python Data Science Handbook》(Jake VanderPlas，免费在线)** 的统计与机器学习部分<br>④ **DeMiguel, Garlappi & Uppal (2009)《Optimal Versus Naive Diversification》** —— 一篇论文，一小时读完，结论极其重要 |
| **产出物** | **一个你自己的形态信号的 IC 检验报告。** 具体做法（这是本阶段的核心动作）：<br>① 把你的形态定义**写成明确的、可被代码执行的规则**（"什么条件出现时标记为买入"）——这一步就会淘汰掉一半模糊的形态<br>② 取过去 3–5 年 A 股全市场（或你熟悉的板块）日线数据<br>③ 计算该信号与**未来 5 日/20 日收益**的 **rank IC**<br>④ 计算 **ICIR** = mean(IC) / std(IC)，并年化（×√252 或 ×√12）<br>⑤ 画 IC 衰减曲线（IC 在 1/5/21/63 日forward return 上的表现）——找出信号的自然持有周期<br>⑥ 关键判断表：<br>　· mean IC < 0.02 → **信号基本无效，放弃或重构**<br>　· mean IC 0.02–0.05 → 弱信号，**必须靠 breadth（很多独立下注）才能有意义的 IR**<br>　· mean IC > 0.05 → 值得继续<br>　· **IC 高但 ICIR 低 → 技能不稳定，方差大，实际不可用** |
| **通过标准** | 你能说出："我的形态信号的 mean IC 是 X，ICIR 是 Y，它在 Z 日的 forward return 上最强。" **——这三个数字，就是你从"有感觉"跨到"有证据"的标志。** |
| **常见错误** | ① **样本量不足**。1 年日线数据只有约 250 个样本，IC 的标准误大到无法判断。② **只看 mean IC 不看 ICIR**（高 IC + 低 ICIR = 不可用）。③ **用全样本调参数后再做样本外检验**（顺序错了 —— 必须先划分样本） |
| **技术障碍** | 这一阶段需要 Python + pandas。**如果你现在的水平只是能看懂均线代码，先花2 周读免费资料补上**（pandas 官方文档 + Python Data Science Handbook + Hilpisch 的 pythonforfinance.io） |

#### 阶段 3 的核心思想（必须内化的 5 句话）

1. **你在测试 1000 个参数，然后挑最好的那个 —— 这个最好的必然是运气。** 需要 Deflated Sharpe Ratio 或等价方法修正。
2. **回测必须用交叉验证，且金融数据要"purged"（剔除标签重叠）+ "embargo"（留出隔离期）。** 否则相邻样本的信息泄漏会让你以为预测能力很强。
3. **样本外表现才是唯一裁判。** 而且要**滚动前推（walk-forward）**，不是随机划分。
4. **等权（1/N）常常打败优化组合。** 优化的收益来自样本内的估计误差。**DeMiguel 2009 是给你省钱的论文。**
5. **一个 IC 只有 0.03 的信号 + 500 个独立下注，IR 可以超过 IC 0.10 但只有 20 个下注的集中选股。** → **宽（breadth）比精（IC）更容易获得，也更适合散户。**

### 阶段 4 · 系统化交易与执行纪律（4–6 周）

| | |
|---|---|
| **目标** | 把阶段 2–3 的结论**固化成不看盘也能执行的东西** |
| **核心材料** | ① **《交易心理分析》第 2 章（交易的诱惑与风险：不愿制定规则/不能负责/沉迷随机报酬）+ 第 7 章（从概率角度思考）**<br>② **Carver《Systematic Trading》第三部分（开源框架）+ "The commitment problem" 系列章节**<br>③ **《止损：如何克服贪婪和恐惧》**（Jim Paul & Brendan Moynihan，中文版《止损》，格致 2016）<br>④ **《非对称风险》第 1 卷（论知识的不确定性）** |
| **产出物** | **一份可执行的《系统运行手册》**：<br>① **入场规则**：什么条件下下单（具体到公式/条件）<br>② **出场规则**：止盈/止损/时间止损，各自有客观条件<br>③ **仓位规则**（引自阶段 2）<br>④ **加仓规则**：**默认"永不加仓"** —— 加仓是最容易破坏风险体系的操作<br>⑤ **降仓与熔断规则**<br>⑥ **禁止操作清单**：明确列出"永远不做"的事（临时改规则、在数据未确认时下单、为"摊薄成本"补仓、因为盘中波动改变判断）<br>⑦ **决策日志模板**：每笔交易记录"规则编号 → 依据数据 → 执行结果 → 是否有规则外的临时决策" |
| **通过标准** | **连续 20 笔交易，规则外决策次数 = 0**（而不是收益好）。 |
| **关于 A 股的三个特殊约束**（英文教材都不会告诉你） | ① **T+1**：当日买入不能当日卖出 → **收盘止损是假的**，你必须用**次日的开盘/盘中**执行，且承担隔夜跳空风险<br>② **涨跌停**：连续一字板时止损单无法成交 → **流动性风险在 A 股是真实的、无法对冲的**<br>③ **卖出印花税 0.05% + 佣金** → **高频策略在 A 股成本结构下几乎不可行**。这直接决定了你只能做**中低频**（这也正好是对的，参见下条） |
| **关键洞察** | **你的约束（A 股 + 个人 + 兼职）不是劣势，它决定了正确的策略类型。** Carver 明确写了这一点：策略必须是"**兼职交易者能管理的**"（manageable by part-time traders）。**A 股散户的最优解是低频、多标的、规则简单、成本可控 —— 不是高频、不是重仓单票。** |

### 阶段 5 · 组合构建与因子视角（8–12 周）

| | |
|---|---|
| **目标** | 从"单个信号"升级到"一个组合"。理解宽度的力量。 |
| **核心材料** | ① **Coursera《Investment Management with Python and Machine Learning》**（EDHEC Business School，4 门课，4.6/5 分，5.5 万人已报名）—— **优先修第 2 门《Advanced Portfolio Construction and Analysis with Python》**：稳健协方差矩阵、Black-Litterman<br>② **Grinold & Kahn《积极型投资组合管理》**（IR = IC × √BR 出处）<br>③ **Antti Ilmanen《Expected Returns》(2011)** —— 可读性优于 Grinold，讲清楚因子为何有效<br>④ **Wes Gray 的 *Quantitative Value* (2012) / *Quantitative Momentum* (2016)** —— 具体实现<br>⑤ **Meb Faber《A Quantitative Approach to Tactical Asset Allocation》(2007)** —— 免费可读，**可直接照抄用于股债/商品切换的资产配置** |
| **产出物** | **一个多标的组合规则**：<br>① **选股范围**：明确的股票池（建议：流动性筛选后的宽基成分股，不要微盘股）<br>② **信号**：可以是你的形态，也可以是动量/价值/质量因子<br>③ **权重规则**：**先用等权**。**在你能跑赢等权之前，不要碰任何优化模型**（DeMiguel 2009）<br>④ **IR 核算**：算出你组合的年化 IC、BR、TC、以及预测 IR，**与你的实际 IR 对比**，看看差距在哪<br>⑤ **再平衡规则**：固定频率（季度/月）还是阈值触发 |
| **通过标准** | 你能回答："我的组合 IR 是 0.4，其中 IC 贡献多少、BR 贡献多少、TC 损失了多少？" |
| **一个重要提醒** | **迁移系数 TC 是你个人投资者的隐形杀手。** Clarke/Thorley 的实证：纯多头约束把 TC 压到 0.4–0.7。**这意味着你理论上的 IR 要打 4–7 折。** 别用高 IC + 少量重仓的组合 —— 在 A 股只能做多，TC 会很低。**这是"为什么散户应该宽而浅"的数学理由。** |

| | |
|---|---|
| **目标** | 建立自己的研究流程与可持续的实盘闭环 |
| **核心材料** | ① **Robot Wealth 博客**（Kris Longmore & James Hodges）—— **实战派标杆**：《Practical Statistics for Algo Traders》系列、《Backtesting Bias: Feels Good, Until You Blow Up》、《The Law of Large Numbers》系列<br>② **Alpha Architect 博客** Academic Research / Factor Investing 分类 —— 每个结论都标注论文出处<br>③ **《金融机器学习》剩余部分**（第 2 部分建模：集成方法、特征重要性、超参数调优；第 3 部分剩余：第 15 章策略风险、第 16 章 ML 资产配置）<br>④ **SSRN 按作者检索**（López de Prado、Ilmanen、Clarke/Thorley、Asness/Moskowitz/Pedersen） |

| **通过标准** | **你能独立完成一次完整的研究闭环**：提出有机制解释的假设 → 明确的数据与样本划分 → 通过全部稳健性检查 → 统计检验显著 → 小资金实盘验证 → 记录并迭代。**这个闭环跑通一次，你就从"有形态基础的散户"变成了"能独立做量化研究的人"。** |

## 5. 全程适用的六条铁律（贴在显示器上）

1. **先活下来，再谈收益。**（Taleb）第一目标是**不要破产**，第二目标是收益。顺序反了的人都会出局。
2. **你必须假设自己是错的。** 所有策略都有失效的一天。**熔断规则的价值在触发那天才体现。**
3. **任何你说不清规则的东西，你就没有规则。** 说不清的，就不是策略，是感觉。
4. **杠杆、频繁交易、重仓单票 —— 这三样东西在 A 股散户身上几乎必然导致归零。** 不是因为它们"不好"，而是因为个人投资者在这三项上没有优势。
5. **成本是确定的，收益是不确定的。** 先算清成本，再谈毛收益。
6. **怀疑自己的信号，是你能获得的唯一免费alpha。** 每一次"这次不一样"的例外，都在为未来的一次崩塌积累概率。

## 6. 关于"读多少书"的现实建议

**这条路不靠读很多书。** 完整读6 本以上高价值书的 A 股个人投资者，极少数能坚持下来。

**推荐的实际投入**：
- **精读（逐章做笔记 + 立刻落地）**：《海龟交易法则》两章 + Carver 博客/书的理论与框架部分 —— **约 10 小时，但会改变你的操作方式**
- **选读（按需要查）**：《金融机器学习》4 章 + Grinold & Kahn 基本法则 + EDHEC Coursera 第 2 门
- **通读（一次）**：《漫步华尔街》相关章节、《交易心理分析》2 章、《止损》
- **只看结论**：Taleb（《非对称风险》第 1 卷）、Grantham（《聪明的宏观》）、西格尔（《投资者的未来》）—— 这三本的价值在于**改变你的默认假设**，快速读过比细读更有效

**⚠️ 关于"一年读50 本量化书"的陷阱**：读得多 ≠ 会用。**这本书档里最危险的书是最容易读的书**（如《聪明的宏观》、《经济学的思维方式》——它们让你"懂了很多"但不改变任何操作）。**每本书的唯一检验标准是：读完之后，我的《交易规则文档》改了几条？如果一条都没改，这本书对你是零价值。**

## 7. 本路径的已知局限

1. **A 股实证数据缺口**：所有方法论都来自美股/欧洲/日本市场。**A 股的 T+1、涨跌停、散户占比、政策驱动的特征，使上述结论需要本地化验证。** 你必须自己在 A 股数据上跑一遍，不能照搬。
2. **阶段 5–6 的组合构建部分，国内缺少可验证的中文实操资源** —— 这也是为什么 Coursera/EDHEC 那门课是**唯一强推荐**（它是英文，但有简中自动字幕）。
3. **本路径不覆盖**：期权/Greeks、税务与遗产规划、外汇与国债期货量化、机构级执行算法 —— 对个人 A 股投资者暂不需要。
4. **时间估算假设**：每周 8–10 小时，且 Python 已有基础。**若 Python 从零开始，阶段 3 之前加 4–6 周。**
5. **阶段 6 的"独立研究能力"没有终点标准** —— 它是一个能力水平，不是可勾选的清单。判断标准是：**你能否识别出自己上一份研究报告的致命缺陷。**
