# 03 · 书籍清单（分层）

> **读者画像**：A 股个人投资者，已具备形态识别基础（技术分析），**最大短板是风险管理能力**。
> **本清单设计原则**：不推荐大量"如何选股"的书，优先补**风险量化、仓位管理、统计检验、回测过拟合**四条线。
> **核实说明**：书名、作者、出版社、年份均经检索核实。**价格为检索到的定价，标注版本；未核实的一律注明"价格未核实"。**
> **核实日期**：2026-10

## 0. 先纠三个常见错误

在开始书目之前，必须先纠正几个流传很广的错认：

| 常见误传 | 事实 |
|---|---|
| 《聪明的宏观》是"Jerome Powell 风格"的作品 | **作者是 Jeremy Grantham（格兰特姆）**，GMO 联合创始人、首席投资策略师。该书原名 *The Making of a Permabear: The Perils of Long-term Investing in a Short-term World*，与 Powell 无关。 |
| 《投资者的未来》是 Seth Klarman 写的 | **作者是 Jeremy J. 西格尔（Jeremy Siegel）**，沃顿商学院金融学教授。Klarman 的书是《安全边际》。西格尔另著《股市长线法宝》。 |
| 《亏钱的力量》是一本投资书 | **查无此书**。你可能想找的是 Jim Paul & Brendan Moynihan 的 *What I Learned Losing a Million Dollars*，中文版译名《止损：如何克服贪婪和恐惧》（格致出版社 2016，原书 Columbia University Press 2013）。 |
| 《A股防雷指南》是一本书 | **查无此书**。你可能想找的是那篇标题为《九大预警指标！收好这本 A 股防雷指南》的**券商研报**（华尔街见闻转载，实为兴业证券金工团队研究，2020-09）。目前能查到的同类实体书是邵辉、包煜楠《投资防雷：那些不可不知的风险》（浙江大学出版社 2024）。 |
| 《赌徒数学》是一本中文投资书 | **查无此中文书名**。三个可能的对象：① William Poundstone《赌神数学家：战胜拉斯维加斯和金融市场的财富公式》（机械工业出版社 2017，ISBN 9787111578826，定价 59 元）——**这是最贴近你需求的一本**；② Edward O. Thorp《The Mathematics of Gambling》(1984)；③ Richard A. Epstein《The Theory of Gambling and Statistical Logic》(Academic Press, 初版 1977/1995 修订版)。 |
| 《滚雪球：价值投资的简易方法》是巴菲特写的 | **是二手摘要/解读，不是原书**。原书是 Alice Schroeder 的《雪球》(Snowball)，中信出版社 2011 年中文版（译者陈旭飞，ISBN 9787802139497）。巴菲特本人从未写过《滚雪球》。 |

## 第0 层 · 风险管理的地基（**最高优先级，你的短板就在这里**）

这一层只有5 本，但每一本都直接补你的短板。

### 1-1 《海龟交易法则》— Curtis Faith
| | |
|---|---|
| 原书| *Way of the Turtle: The Secret Methods that Turned Ordinary People into Legendary Traders* (McGraw-Hill, 2007) |
| 中文版| 中信出版社 2013，译者乔江涛，ISBN 9787508639093，**249 页，定价 59 元**，豆瓣 8.5 |
| **难度** | **入门** |
| **为什么值得读** | **这是你的第一本书。**它是唯一一本把"仓位管理 + 止损 + 头寸规模计算"讲成可执行规则的入门书。核心是每个品种按 N（ATR 波动率）计算头寸，使每笔交易风险恒定——这是你在形态识别之外最缺的能力。海龟试验的 13 人被培训两周后4 年年均 80% 收益，本身就是"交易技能可教"的证据。书中第7 章"如何衡量风险"、第 8 章"风险与资金管理"、第 11 章"历史测试的谎言"、第 12 章"历史测试的统计学基础"直接对应你的短板。 |
| **替代品** | 无。这是该主题唯一一本"中文+可执行+不过度数学"的书。若读不进去，直接跳到 Carver 的《Systematic Trading》第一部分。 |
| 注意 | 它讲的是**期货**（原版标的），A股个股直接套用要改造（无做空、无当日止损、T+1）。但**仓位计算逻辑与品种无关，可以直接迁移**。 |

### 1-2 《非对称风险》— Nassim Nicholas Taleb
| | |
|---|---|
| 原书| *Skin in the Game: Hidden Asymmetries in Daily Life* (2018) |
| 中文版| 中信出版社 2019.1，译者周洛华，ISBN 978-7-5086-9847-2，**343 页，定价 68 元** |
| **难度** | **入门（但需反复读）** |
| **为什么值得读** | 副标题是"风险共担"。核心命题：**当决策者不承担后果时，他不会做对的决策**。对个人投资者的直接映射：券商卖方分析师的评级、财经大V的荐股、你的自媒体"老师"——全是"收益归他、亏钱归你"的负非对称结构。这本书训练的是**你识别负非对称的能力**，这是风险管理的元技能。塔勒布在书中提出的"副作用原则""少数人的盛宴""天真的干预"三条判断规则，可以直接当决策检查清单用。巴菲特评价塔勒布："我读他的书比读任何其他人的书都多。" |
| **替代品** | 塔勒布四部曲按对个人投资者的相关度排序：《非对称风险》> 《反脆弱》(Antifragile) > 《随机漫步的傻瓜》(Fooled by Randomness) > 《黑天鹅》。**如果只读一本，读《非对称风险》。** |
| 补充 | 《黑天鹅》(2007) 讲的是**不要预测、只在极端事件中生存**，方法论层面已经被《反脆弱》超越。作为入门读《非对称风险》已足够。 |

### 1-3 《金融机器学习》(Advances in Financial Machine Learning) — Marcos López de Prado
| | |
|---|---|
| 原书| Wiley, **2018 年 2 月**，ISBN 978-1-119-48208-6，400 页 |
| 中文版| 中信出版社 2021.5，译者林华，ISBN 978-7-5217-2809-5，**440 页，定价 99 元** |
| **难度** | **专家**（本书最硬，但**每一章都直接对应你的短板**） |
| **为什么值得读** | **这是"统计检验"这条线的唯一入口，也是把"形态识别"从感觉升级为可量化研究的关键。** 核心章节：<br>· 第 7 章 **金融领域的交叉验证**（purged K-fold、embargo）—— 这是解决回测过拟合的核心技术<br>· 第 11 章 **回测的风险**（Deflated Sharpe Ratio，解决"试了 1000 个参数挑最好那个"的统计陷阱）<br>· 第 13 章 **基于合成数据的回测**<br>· 第 14 章 **回测统计量**（Probabilistic Sharpe Ratio、Minimum Trackback Length）<br>· 第 10 章 **投注规模**（Kelly / 分数 Kelly）——**这是仓位管理的理论依据，海龟只是它的简化版**<br>作者是 AQR 机器学习负责人、康奈尔教授、Erdős #2。这是一个真正的量化从业者写的书，不是二手综述。 |

| 中文版质量 | 翻译质量口碑良好（林华，CFA）。第 5 部分（高性能计算）对个人投资者**可以整章跳过**。 |

### 1-4 《主动投资组合管理》/《积极型投资组合管理》— Richard C. Grinold & Ronald N. Kahn
| | |
|---|---|
| 原书| *Active Portfolio Management* (McGraw-Hill) |
| 中文版| 中信出版社《积极型投资组合管理：控制风险获取超额收益的数量方法》，初版约 1994 年译出；第二版新增资产配置、多空、信息区间等内容 |
| **价格** | **价格未核实** |
| **难度** | **进阶（数学）** |
| **为什么值得读** | **这是 IR = IC × √BR 这条公式的出处**（CFA 考试必考）。对你而言它的价值不在公式本身，而在**提供一个判断"我这个策略到底有没有真本事"的量化标尺**：<br>· IC（Information Coefficient）= 你的选股/择时信号与未来收益的相关性。**你完全可以自己算**：把形态信号转成打分，回测它与次日/次日周收益的 rank IC。<br>· 实战参考值：IC 通常 0.02–0.05 就算不错，0.05–0.08 是机构里的优秀水平。**如果你算出的 IC 是 0.01，那这个信号不值得交易。**<br>· BR（breadth）是独立下注次数。**关键陷阱**："独立"二字。持有 500 只股票但都押同一个行业动量，那不是 500 个独立下注，公式会严重高估你的 IR。 |
| **替代品** | **如果这本书读不动，替代方案是先读Antti Ilmanen《Expected Returns》(2011)** —— 更厚但可读性更好，讲清楚为什么动量/价值因子长期有效（风险溢价 + 行为机制两条线）。Ilmanen 现在在 AQR，Carver 和他合写过 *Systematic Investing* 系列。 |
| 中文版注意 | 中文译名《积极型投资组合管理》，检索"主动投资组合管理"也能找到，**注意区分这是同一本书**。 |

### 1-5 《Systematic Trading》— Robert Carver
| | |
|---|---|
| 原书| Harriman House，ISBN 9780857194459（纸）/ 9780857195005（电子），**约 47.99 美元** |
| 中文版| **无官方简体中译本**（检索未发现，**价格未核实**） |
| **难度** | **进阶** |
| **为什么值得读** | **这本书可能是清单里性价比最高的一本。** Carver 是职业系统化交易对冲基金经理，出身于统计学教育（他的学术本职是研究"统计教育"，所以他讲统计讲得极清楚）。<br>内容分三部分：<br>· **理论**：为什么系统化交易有效（风险溢价 + 摩擦 + 行为效应），以及系统化交易的"三个罪"：**过拟合（overfitting）、过度交易（overtrading）、过度下注（overbetting）**——请把这三个词记住，它们是你这个阶段的核心敌人。<br>· **工具箱**：模型选择与拟合的"四条有效拟合规则"（**先少量想法而非先有数据、把真实数据留着下雨天才用、不到枪口对准脑袋不拟合、非拟合不可就要极度小心**）、组合配置为什么"很难"以及"自助法(bootstrapping)"这个简单修复。<br>· **框架**：一套开源式的系统框架——交易工具 → 信号（单位方差标准化！）→ 预测 → 仓位缩放 → 组合 → 资金管理 → 风险度量与控制。<br>**"头寸规模与头寸方向同等重要"（Sleep at night: position size is as important as position sign）** 这一章直接是你的核心缺口。<br>业内评价（Andreas Clenow、Acies 资产管理 CIO）："我读过几乎所有主要交易投资书，这是15 年来最好的一本。" |
| **替代品** | 若读英文吃力，可用**第二作者身份的中文讲义**：Carver 的 "Advanced Futures Trading Strategies" 与他的博客 qoppac.blogspot.com（他本人称"这个博客是我写给自己的笔记"，**免费、体系完整、实战派**）。另外 Carver 另有 *Systematic Investing* 系列（与 Jelle Stobbe 合作），讲跨资产配置。 |

## 第 3 层 · 交易心理与纪律
