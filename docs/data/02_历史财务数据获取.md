# 历史财务数据获取指南

> 目标：拿到 A 股全市场**多期财务时间序列**（利润表 / 资产负债表 / 现金流量表 / 财务指标）
> 调研时间：2026-10-02

---

## 一、先明确需求：你要的是"时间序列"还是"快照"

| 数据形态 | 能做什么 | 当前状态 |
|---|---|---|
| **单期快照**（本机 `base.dbf`） | 算静态 ROE、PB、PE、筛"高 ROE 低 PB" | ✅ 已有 7,992 条 |
| **多期序列**（8~40 个季度） | 算**净利润同比增速**、**ROE 连续性**、**现金流质量趋势** | ❌ 缺失，**这是最大短板** |

为什么单期快照不够用——三个具体例子：

1. **ROE 连续性**：单期 ROE 12% 可能是周期顶点的产物，也可能连续 8 年稳定在 12%。这两种股票完全不是一回事。
2. **利润质量比**：需要「经营现金流 / 净利润」的时间序列。单期比值为 1.2 可能是稳定，也可能某几年是 0.3。
3. **成长性**：必须有同比，而同比需要至少 4 个季度。

## 二、免费方案

### 方案 A：akshare（完全免费，最推荐先用）

```python
import akshare as ak

# 利润表（按报告期）
ak.stock_financial_report_sina(stock="sh600519", symbol="利润表")
ak.stock_financial_report_ths(stock="600519", indicator="按报告期", symbol="利润表")

# 关键财务指标
ak.stock_financial_abstract_ths(stock="600519", indicator="按报告期")

# 业绩快报 / 业绩预告
ak.stock_yjbb_em(date="20260930")     # 业绩报表
ak.stock_yjyg_em(date="20260930")     # 业绩预告
```

**实测提醒**（本机验证）：
- ✅ `stock_zh_a_daily`（新浪源）**可用**
- ❌ `stock_zh_a_hist`（东方财富源）**被代理拦截**
- 建议：`pip install efinance` 作为冗余（走东财+同花顺+新浪聚合）

| 优点 | 缺点 |
|---|---|
| 完全免费、无需 token | 接口偶发缺失，需自行清洗 |
| 覆盖 A 股特有数据 | 实时接口延迟约 500ms，不适合高频 |
| 社区活跃 | 财务数据**不完整**（缺历史季度） |

### 方案 B：Tushare（免费额度 + 积分制度）

**积分门槛（关键）**：

| 积分 | 价格 | 可获取 |
|---|---|---|
| 100 分 | 注册即得 | 日线、指数、股票列表、**基础财务** |
| **2000 分** | **约 200 元/年** | 日/周/月线、**财务报表完整版**（三表） |
| 5000 分 | 约 500 元 | **分钟线、逐笔数据、龙虎榜** |
| 10000 分+ | 约 1000 元 | 全部接口 |

**获取积分**：每日签到 +1 分、分享注册 +500 分、论坛发帖 +5~50 分、**捐赠按金额换算**（最直接）。

核心接口：
```python
pro.income(ts_code='600519.SH', period='20250930')       # 利润表
pro.balancesheet(ts_code='600519.SH', period='20250930')  # 资产负债表
pro.cashflow(ts_code='600519.SH', period='20250930')     # 现金流量表
pro.fina_indicator(ts_code='600519.SH', period='20250930')# 财务指标
pro.adj_factor(ts_code='600519.SH', start_date='')        # 复权因子
```

**评价**：字段质量最高、国内网络稳定（走 tushare.pro HTTPS）。**200 元/年是性价比最高的财务数据支出**。

⚠️ **重要事件**：2026 年 TusharePro 突发停运，量化圈震动。教训是**不要把数据源单点依赖**。

### 方案 C：Baostock（零配置兜底）

```python
import baostock as bs
bs.login()   # 无需注册、无需 token
bs.query_history_k_data_plus("sh.600519", "date,code,open,high,low,close,volume,amount,turn,peTTM,pbMRQ,psTTM,pcfNcfTTM", ...)
bs.query_profit_data(code="sh.600519", year=2025, quarter=2)   # 利润表
bs.query_balance_data(...)   # 资产负债表
bs.query_cash_flow_data(...) # 现金流量表
bs.query_dupont_data(...)    # 杜邦分析
```

**特色**：官方合作，A股历史财报 + K 线稳定，数据**很少缺失或错误**，无需注册。
**限制**：仅 A 股；需 `login()`。

## 五、缓存与存储

拉到本地后立刻落盘，避免重复请求：

```
data/financial.db
├── income      (code, report_date, revenue, op_profit, net_profit, ...)
├── balance     (code, report_date, total_assets, total_liab, equity, ...)
├── cashflow    (code, report_date, ocf, icf, fcf, capex, ...)
├── indicator   (code, report_date, roe, roa, gross_margin, debt_ratio, ...)
└── adj_factor  (code, date, adj_factor)   ← 复权因子，极其重要
```

**`adj_factor` 一定要单独存**——没有它，前复权算不出来，所有历史价格对比都是错的。
