# A 股量化算法方案清单与落地路线（2026-10-05）

> **本文定位**：在已有实测结论（见 `03_A股量化算法全景对比.md`）基础上，
> 回答「哪些算法值得用、开源实现有哪些、按什么顺序落地」。
>
> **本机硬件前提（决定了大量选型）**：8 物理核 / 16 逻辑核、13.9 GB 内存、
> 708 GB 可用磁盘、**无 NVIDIA GPU**。

## 一、名词解释（先看懂后面）

| 术语 | 一句话解释 | 与相近概念的区别 |
|---|---|---|
| **IC（信息系数）** | 因子值与**未来收益**的秩相关系数，衡量「这个指标能不能预测涨跌」。取值 −1~+1，0 就是瞎猜 | 与「准确率」不同：IC 衡量**排序能力**（谁会涨得更多），准确率衡量**方向**（涨还是跌）。IC 0.05 意味着能排对前 5% |
| **ICIR** | IC 的均值 ÷ IC 的标准差，衡量信号的**稳定性** | 与 IC 的区别：IC 看强度，ICIR 看可靠度。业界公认 **ICIR>0.3 才算可用** |
| **RankIC** | 把因子值和收益都转成名次再算相关，= Spearman 相关 | 与普通 Pearson 相关的区别：对极端值不敏感，不会被个别暴涨股带偏 |
| **多空组合** | 同时做多最高分组 + 做空最低分组，押注「高的比低的好」 | **A 股散户无法做空**，所以这个数字只能当作「因子的相对强度」，不是你实际能拿到的收益 |
| **中性化** | 剔除因子里能被「行业」「市值」解释的部分，只留个股特有的信号 | 与「标准化」不同：标准化统一量纲，中性化剥离干扰项。不做中性化，「价值因子」实测出来常常只是「小市值因子」 |
| **换手率** | 持仓每期变动的比例 | 换手直接决定成本。A 股往返约 20bp，**换手 10%/日 = 年成本 20%**，几乎吃掉任何毛收益 |
| **盈亏平衡换手率** | 毛收益 ÷ 单次成本 × 分组数，即「换手多高还划算」 | 是判断策略可行性的第一道闸门 |
| **前视偏差** | 回测里用了当时还拿不到的信息（最常见：财报披露前就用上财报） | 与「过拟合」不同：前视偏差是**数据错**，过拟合是**参数错**。两者都会让回测虚高 |
| **样本外（OOS）** | 训练期之外的数据 | 金融上唯一可信的检验标准。全样本表现好 = 过拟合的信号 |
| **purged K-fold + embargo** | 交叉验证时剔除标签重叠样本并在训练/测试间留空隙 | 普通 K-fold 在时序金融中会**泄漏未来**，必须用这种 |
| **DoubleEnsemble** | Qlib 里的集成模型：对 LightGBM 的残差再用第二个模型修正 | 与普通集成不同：它专门处理「弱模型 + 弱特征」的场景，官方基准里效果最好 |
| **Alpha158 / Alpha360** | Qlib 预置的标准化特征集，分别 158/360 个特征 | 与自定义因子不同：它们是**统一口径**，跨论文/跨模型可比较。Alpha360 是未经特征筛选的原始版 |
| **MS (microsoft 股票)** | microsoft 之外还包含因子组合建模、组合优化、订单执行 | 它是「流水线」，不是一个模型 |
| **卖点/拥挤度** | 跟踪同一因子的资金过多导致其收益下降 | 因子失效的**预警指标**，不是收益来源 |

## 二、方案清单（按「效果 / 开销 / 成熟度」综合排序）

数据来源：Qlib 官方基准（CSI300，Alpha158，**20 个随机种子均值**）+
本机实测 + 公开研报。**注意：官方基准未明确是否计入交易成本**，
本机实测一律按往返 20bp 计算。

### 2.1 传统机器学习（树模型 + 线性）

| 方案 | Qlib 官方年化 / IR | 本机可复现 | 计算开销（本机实测） | 训练耗时 | 工程成熟度 |
|---|---|---|---|---|---|
| **Linear / Ridge** | +6.92% / 0.92（Alpha158） | 易 | CPU 单核，秒级 | <1 分钟 | ⭐⭐⭐⭐⭐ |
| **LightGBM** | +9.01% / 1.02 | 易 | CPU 单核，全市场约 20 分钟 | 5~20 分钟 | ⭐⭐⭐⭐⭐ |
| **XGBoost** | +7.80% / 0.91 | 易 | 同上，略慢 | 10~30 分钟 | ⭐⭐⭐⭐⭐ |
| **CatBoost** | +7.65% / 0.80 | 易 | 同上 | 10~30 分钟 | ⭐⭐⭐⭐ |
| **DoubleEnsemble** | **+11.58% / 1.34**（最高） | 中（需装 Qlib） | CPU，约 4 小时（第三方实测） | 2~6 小时 | ⭐⭐⭐⭐ |

**注意一个反直觉点**：XGBoost 在 Alpha158 上的 **IC（0.0498）高于 LightGBM（0.0448）**，
但 LightGBM 的年化收益与 IR 更高。所以「谁更好」取决于你看IC 还是看收益。

### 2.2 深度学习

| 方案 | Qlib 官方年化（Alpha158 / Alpha360） | 本机可复现 | 显存需求 | 成熟度 |
|---|---|---|---|---|
| **MLP** | +8.95% / **+0.29%** | CPU 可跑但慢 | CPU 即可 | ⭐⭐⭐⭐ |
| **GRU** | +3.44%（20特征）/ **+7.20%** | CPU 勉强 | CPU 即可 | ⭐⭐⭐ |
| **LSTM** | +3.81%（20特征）/ **+6.47%** | CPU 很慢 | CPU（数天） | ⭐⭐⭐ |
| **Transformer** | +2.73% / **−2.70%** | ❌ 需GPU | 8~16 GB | ⭐⭐⭐⭐ |
| **TCN / IGMTF / HIST** | +2.62% / +6.04% / +9.87% | ❌ 需 GPU | 8~24 GB | ⭐⭐ |

**核心事实：在 Alpha360（原始未筛选特征）上，除 HIST 外深度学习基本全线崩溃，
Transformer 甚至是负的。** 只有经过特征筛选（Alpha158）或专门架构设计，
深度学习才勉强追上树模型。

**本机无 GPU，所以这一整类方案直接排除**（MLP/GRU 勉强能跑但耗时不可接受）。

### 2.3 本机已验证的因子路线（本项目实测，最推荐）

| 方案 | 全样本年化毛/ 净 | 三段净收益 | 换手 | 成熟度 |
|---|---|---|---|---|
| **bp 单因子** | +12.9% / **+3.2%** | +1.0 / +7.1 / +2.2% ✅ | 3.9% | ⭐⭐⭐⭐⭐ |
| **cf_quality 单因子** | +4.0% / **+0.6%** | 三段全正 ✅ | 1.3% | ⭐⭐⭐⭐⭐ |
| **bp + cf_quality 等权** | +11.1% / **+2.8%** | +3.87 / +4.82 / +1.15% ✅ | 3.3% | ⭐⭐⭐⭐⭐ |
| **bp + cf_quality IC加权** | +13.9% / **+4.1%** | +3.62 / +7.10 / +2.21% ✅ | 3.9% | ⭐⭐⭐⭐ |
| bp + cf_quality + roe + profit_yoy | — | **出现负段** ❌ | 4.8~6.0% | ⭐⭐⭐ |

⚠️ 全部为**多空组合口径**，A 股散户无法做空。

## 三、每个方案的适用条件、优缺点、失效场景

### 3.1 因子路线（本机首选）

**适用条件**
- 资金规模不大（日频换手 3~4% 可承受）
- 能接受「某些年份不赚钱」
- 持有周期 3 个月以上（换手率决定成本）

**优点**
- **不需要 GPU**，本机即可全市场检验（36 秒/因子）
- 因子可解释，能说清「为什么买这只」
- 已通过三段子区间检验，不是过拟合

**缺点**
- 净收益只有个位数
- 依赖「因子还有效」这个前提，一旦失效无预警

**典型失效场景**
- **制度变更**：小市值因子在注册制全面实施后失效四年
- **风格切换**：2019.4–2021.1 价值因子因白马抱团回撤 30%
- **拥挤**：因子被大量资金跟踪后收益下降
- **稀释效应**（本项目新发现）：加入 roe / profit_yoy 后，
  三种合成方法**净收益全部变差**，子区间从全正变为有负段。
  → **因子不是越多越好，加因子前必须先确认它三段稳健。**

### 3.2 树模型（LightGBM / XGBoost）

**适用条件**
- 有 Alpha158 级特征工程能力
- 愿意接受调参与过拟合风险
- 需要比单因子更稳定的排序能力

**优点**
- 自动发现因子间的非线性交互
- Qlib 有现成基准可对标，可复现性强

**缺点**
- **成本是硬约束**。Qlib 官方实测：同策略不计成本年化 17.83% / IR 2.00，
  **计入成本后 12.90% / IR 1.44 —— 损耗 28%**
- 特征重要性 ≠ 因果关系，可能是代理变量
- 官方基准**未明确是否计入成本**，跨论文比较要小心

**典型失效场景**
- 随机划分 train/test（时序金融中会泄漏未来）
- 用当前存续股票训练（幸存者偏差；印度市场研究量化：高估年化 4.94pp）
- 财务数据用报告期末日而非实际披露日对齐

### 3.3 深度学习

**适用条件（本机全部不满足）**
- 需GPU
- 需Alpha360 级原始特征 + 长期积累

**优点**：理论上能捕捉最复杂的时序依赖

**缺点**：在 A 股实证上**不如树模型**；换手率极高，扣费后常为负

**典型失效场景**
- 原始价量数据上Transformer 年化 **−2.70%**
- 51% 的准确率（≈ 抛硬币 49.95%）在 20bp 往返成本下无经济意义

### 3.4 强化学习 / 时间序列方向预测 / 统计套利

**本项目结论：不建议。** 详见主报告第五、六、七节。
一句话：RL 的 A 股实盘业绩无公开数据、时序方向预测 AUC 0.52（≈随机）、
统计套利在 3‰佣金下收益为负且融券成本 8%+。

## 五、推荐落地路线（以「最快达到最好效果」为目标）

### 阶段 0：已具备（无需再做）
- ✅ 本机通达信 16.4M 日线（9,595 标的，2015-12 起）
- ✅ 46 期季度财务面板（11,740 只）
- ✅ alphalens-reloaded 因子检验框架 + 全市场五步冒烟
- ✅ 已验证 bp 三段净收益全正

**预期收益**：无需投入
**风险**：无

### 阶段 1：两因子等权组合（约 1 天工作量，**强烈建议从这开始**）
**做什么**
1. 用 `bp + cf_quality` 等权合成（已实测：三段净 +3.9%/+4.8%/+1.2%）
2. 月频或季频调仓（把换手从 3.3%/日压到可忽略）
3. 只做多头（剔除净收益最低的 20%）

**预期收益**：全样本多空净 +2.8%（扣 20bp 往返）
**风险**：低。已通过三段检验
**放弃条件**：连续两个季度实际扣费后收益为负 → 转入阶段 2

⚠️ **前提条件**：这个数字是多空口径。实际多头收益约为其**60%~70%**，
且未扣除你自己的交易成本冲击。**必须先用模拟盘跑 2 个季度验证**。

### 阶段 2：加入 IC 加权（约 2 天）
**做什么**：用滚动 252 日 IC 替代等权（实测三段净 +3.6%/+7.1%/+2.2%，全样本最优）

**为什么不是第一步**：IC 加权引入了额外参数（窗口长度），
在 400 只小样本上曾出现「IC 加权反而比等权差」的情况（+0.13% vs +5.24%），
说明它对样本量和窗口敏感。等权无参数，更稳健。

**预期收益**：净收益从 +2.8% 提升到 +4.1%
**风险**：中。参数选择不当会退化
**放弃条件**：窗口在 120/252/504 三档下结果差异 > 50% → 说明不稳定，退回等权

### 阶段 3：加第三个因子（约 3 天，**必须先验证再加入**）
**做什么**：每加一个因子，跑一次三段检验；**只有三段净收益全正的才允许加入**

**关键警告**：本项目已实测——直接加入 roe + profit_yoy，
三种合成方法的净收益**全部变差并出现负段**。
「多因子」不等于「因子越多越好」。

**预期收益**：理论上提升，实际可能下降（取决于新因子的稳健性）
**风险**：中高。最容易在这里犯「越多越好」的错
**放弃条件**：任何因子导致子区间出现负段 → 立即剔除

### 阶段 4：Qlib 树模型对标（约 1~2 周，**可选**）
**做什么**：把阶段 1~3 的因子送进 Qlib LightGBM，看能否提升排序能力

**预期收益**：官方基准单因子 vs LightGBM 是 3.2% → 9.0%，
但**这是 Qlib 自带的 Alpha158 特征，不是你的两因子**。迁移到你的因子上，
提升幅度未知，很可能远小于此。

**风险**：高。特征工程是主要成本，且极易过拟合
**放弃条件**：加入 ML 后**净收益低于阶段 1~3 的最优值** → 回到因子路线

### 阶段 5：GPU 深度学习 —— **现阶段不建议**
**为什么不建议**
1. **本机无 GPU**，无法训练
2. Qlib 官方基准显示深度学习在 A 股**不如树模型**
   （Alpha360 上 Transformer 年化 −2.70%）
3. 需要 Alpha360 级特征集 + 长期积累，工程投入以月计
4. **换手率极高**——深度模型的高 IC 通常伴随高换手，扣 20bp 后趋近于零
5. 券商实盘跟踪中，AttentionGRU 2026 年以来**累计跑输基准 1.72pp**
   （对比：XGB+MLP 串行模型跑赢 13.58pp）

**若将来要做，前置条件**：① 购入 GPU（≥12 GB 显存）② 先跑通Qlib 官方基准复现
③ 确认自己的数据能构造 Alpha360 级特征 ④ **且必须证明扣费后净收益为正**

## 六、明确不建议现阶段采用的方案（工程代价过高）

| 方案 | 不建议理由 | 何时再考虑 |
|---|---|---|
| **深度学习（LSTM/Transformer/TCN）** | 本机无 GPU；A 股实证不如树模型；换手高导致扣费后趋零 | 有 GPU + 已复现 Qlib 基准 + 有 Alpha360 级特征 |
| **强化学习** | A 股实盘业绩**无任何公开可验证数据**；空头腿需融券（成本 8%+，券源稀缺） | 融券成本降至 2% 以下，且有 GPU |
| **统计套利 / 配对交易** | 线性协整法在 3‰佣金下收益为负；融券规模累计降 64%/75% | 融券恢复 + 有分钟级数据 |
| **因子择时** | Wu (2024)：24 个因子里只有反转因子有稳健样本外可预测性；本项目实测 bp 的三段差异已达 6pp | 有稳定的择时信号且样本外验证通过 |
| **mlfinlab** | **已停更 3 年（2023-10）+ 新版需商业许可** | 换商业许可（不推荐） |
| **LangChain / 大模型直接预测股价** | 无公开的 A 股有效证据；幻觉率高；不可复现 | 不建议 |

## 七、一句话回答你的核心问题

> **最快的路不是「用最好的算法」，而是「用已被本机全市场实测、三段稳健的 bp + cf_quality 两因子等权」，然后按「加因子前必须验证三段」和「换手率决定生死」两条纪律迭代。**
>
> 深度学习和强化学习在 A 股目前**不是「理论更优但工程代价高」，而是「实测效果更差」**——这一点与直觉相反，但有Qlib 官方基准、券商实盘跟踪和本项目实测三重证据支持。
