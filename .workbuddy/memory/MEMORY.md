# MEMORY.md · 长期项目笔记

## 用户画像（通达信投研会话）

- A 股个人投资者，通过通达信 MCP 连接器做选股与技术形态筛选。
- **能力水平**：能提出「日线 + 周线双周期共振」这类进阶筛选条件，也会主动质疑工具有效性（曾问「黄金分割有道理吗、经过市场验证吗」；本次会追问「硬件资源没有充分利用」）。
  但同时会回头追问基础术语（H / L / HH / HL、什么是支撑位），说明其知识结构是「**会用工具但概念未成体系**」：能凭直觉操作，但缺少严格定义。
  → **答复策略**：使用专业术语时必须随手给出简要定义，不可默认用户已掌握；概念讲解要配图 + 大白话释义。
- **短板**：风险管理。提问习惯集中在「给我能赚钱 / 大大概率赚钱的股票」，极少涉及仓位规模、止损执行与交易复盘。
- **表达偏好**：要求结论明确、给出可执行价位（买点区间、止损线、目标位）；接受坦率直白的风险提示，不需要客套。
- **内容深度要求（重要）**：用户两次明确嫌内容太浅。要求**底层原理 + 数学推导 + 可验证算例**，可以长、可以信息密度高，但**不允许泛泛而谈或说教式罗列**。
- **案例必须用真实行情（重要）**：禁止使用「假设某策略胜率 55%」这类抽象模型。案例必须取自通达信真实数据——**具体股票代码 + 具体日期 + 具体价格**，用户会自行复核。做教程时应主动拉取真实 K 线数据作为素材。
- **呈现要求**：图文并茂，每个知识点配图（SVG/图表）；新概念先给「大白话解释」再展开；篇幅要足，宁长勿短。用户明确表示「华丽花哨但没实际内容没意义」。**但也曾明确说「不要浪费时间做无用功，比如 html 网页」——所以优先纯文字/Markdown，图表用内联SVG，不要做 HTML 页面。**
- **效率敏感（2026-10-05 新增）**：会检查资源利用率。**长任务必须并行化，不要单线程跑全市场**；跑之前先 profile 找瓶颈。

## 协作约定

1. 荐股答复**必须同时包含**：止损位（跌破即离场的具体价格）、仓位建议、板块集中度风险。只给标的代号视为不合格。
2. 数据一律标注来源（通达信）与截止日期；休市期间必须写明「数据截至 YYYY-MM-DD 收盘」。
3. 所有投资相关结论结尾声明「不构成投资建议」。
4. 用户容易把「这只会不会赚钱」作为唯一目标，需主动把讨论拉回**期望值 / 赔率 / 风险控制**的框架。
5. **写报告时必须附带口径声明**（见 AGENTS.md 第八节）：多空组合口径（A 股散户无法做空）、幸存者偏差、市值用当前股本快照、未做多重比较校正。
