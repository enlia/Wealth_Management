# 选股能力实测结果与使用指南（2026-10-05）

> **数据**：通达信本机 16.4M 日线 / 11,740 只季度财务
> **样本**：全市场 5,185 只 A 股 × 2,611 交易日（2016-01-01 ~ 2026-09-30）
> **成本**：往返 20bp（佣金万2.5 + 印花税千0.5 + 滑点万5）
> **硬件**：8 物理核；下列结果全部由 CPU 完成（本机 GPU = RTX 4060 Laptop 8 GB，2026-10-07 实测 CUDA 就绪，未参与该批实验）

---

## 一、结论：选股能力提升了，但赚钱能力没提升

| 指标 | 数值 | 含义 |
|---|---|---|
| **准不准：20 日命中率** | **54.0%** vs 全市场 46.4% | **+7.6pp** |
| **准不准：60 日命中率** | **51.3%** vs 全市场 44.0% | **+7.3pp** |
| 持有 60 日胜率 | 54.6% | 十次交易约 5.5 次赚 |
| 盈亏比 | 1.29 | 平均赚的钱是平均亏的 1.29 倍 |
| **赚钱能力：年化净收益** | +4.88% | 基准 +4.43% |
| **赚钱能力：年化超额** | **+0.12pp** | ⚠️ 只有 0.12 个百分点 |
| 最大回撤 | **−44.84%** | ⚠️ 最坏时接近腰斩 |
| 夏普 | 0.22 | 风险调整后收益很低 |
| 年换手 | 2.0%（年成本 0.02%） | 成本几乎可忽略 |

**一句话**：选股确实更准了（命中率 46.4% → 54.0%），但这个优势在**盈亏比和回撤**上被消耗掉了，最终只换来 +0.12pp 的年化超额。

## 二、最重要的发现：之前因子筛选用错了前瞻期

我此前用**1 日前瞻 IC** 判断因子有效性，结论完全错了。

**全市场真实数据**（中性化后 Spearman IC）：

| 因子 | IC_1日 | IC_20日 | IC_60日 | IC_120日 | 我之前的判定 |
|---|---|---|---|---|---|
| **drawdown_60** | +0.158 | **+0.501** | **+0.479** | +0.253 | ❌ 没注意到 |
| illiq_accel | +0.055 | +0.241 | +0.055 | +0.028 | ❌ 剔除了 |
| vol_ratio_20_60 | −0.010 | +0.231 | +0.146 | +0.063 | ❌ 剔除了 |
| skew_60 | −0.006 | +0.139 | +0.304 | +0.196 | ❌ 剔除了 |
| range_20 | −0.035 | +0.167 | +0.269 | +0.274 | ❌ 剔除了 |
| turnover_20 | −0.024 | +0.072 | +0.136 | +0.141 | ❌ 剔除了 |
| — | | | | | |
| **bp**（我当成最强） | −0.002 | −0.060 | **−0.112** | **−0.149** | ✅ 当成可用 |
| **low_vol_120** | +0.030 | +0.019 | **−0.038** | **−0.123** | ✅ 当成可用 |
| low_vol_60 | +0.031 | −0.014 | −0.150 | −0.203 | ✅ 当成可用 |

**根因：A 股 T+1 制度。** 日内收益 +28.22%、隔夜收益 −13.85%（方向相反），
所以任何因子的 **1 日 IC 都被日内噪声污染**。而 `bp`、`low_vol_120`
这些在 60~120 日其实是**负向**的。

**`drawdown_60`（距 60 日高点的回撤）IC_20 = +0.5014，是本项目最强的单因子信号**，
比此前认为最强的 bp（+0.0261）高 19 倍。

## 三、组合构建：TopkDropout

早期试了三种缓冲方案都失败（记录在 `holding_period_test.py` 的函数注释里）：

| 版本 | 问题 |
|---|---|
| 5 组等权平均当组合收益 | 收益被稀释，且与调仓频率无关（三种配置结果完全相同） |
| 绝对分位边界保留持仓 | 调仓越慢换手反而越高（0.53%→1.28%→1.97%） |
| 缓冲区扩大目标持仓数 | 单次换手 90%+ |
| **最终：固定持仓数 + 每次只换最差/最好 n_drop 只** | ✅ 换手 = n_drop/N × (252/调仓间隔)，完全可控 |

实测结果（每 120 日调仓 / 每次换 5 只）：

- 年化净 +4.88%，基准 +4.43%，**超额 +0.12pp**
- 20 日命中率 54.0% vs 全市场 46.4%（**+7.6pp**）
- 年换手仅 2.0%，年成本 0.02%

## 四、为什么命中率 +7.6pp，超额只有 +0.12pp

这是本项目**尚未解决**的核心矛盾。三个原因：

**1. 命中率是概率，超额是幅度加权**

盈亏比只有 1.29 —— 赢的时候幅度小，输的时候幅度大。
十次赢六次但每次赚 1.29 分，被输的那 4 次抵消掉。

**2. 同期基准本身在涨**

2016-2026 全市场等权年化 +4.43%。这是 A 股整体的上行周期，
超额空间天然被压缩。

**3. 最大回撤 −44.84% 是真正的硬伤**

这不是选股问题，而是**仓位/风控问题**。要解决需要择时或止损，
但因子择时在 A 股基本被证伪（Wu 2024：24 个因子里只有反转因子
有稳健的样本外可预测性）。

**→ 瓶颈已经从「选不出好股票」转移到「控不住回撤」。**

## 五、使用它有什么门槛（诚实版）

### 需要什么

| 项目 | 要求 | 说明 |
|---|---|---|
| **数据** | 至少 3 年日线 | 本项目用的是通达信本地数据 |
| **计算** | 普通电脑即可 | 全市场 5,185 只跑一轮约 20 分钟，8 核 CPU |
| **软件** | Python + pandas | 需自己写或改造本项目脚本 |
| **维护** | **每季度重跑一次** | ⚠️ 最容易被忽略的一项 |
| **纪律** | 严格执行，不临时改规则 | 见下方失效风险 |

### 三个真实风险

**风险 1：因子会失效**

2019-2022 年基本面因子曾整体大幅跑输（国泰海通语）。
本项目的 `bp` 因子在 60 日口径下已经变成负向。
**如果 2027 年 drawdown_60 也失效，你不会提前知道。**

**风险 2：数据精度**

本项目用通达信 `.day` 格式，**未处理复权**（除权日价格会跳空）。
专业数据源（Tushare/AkShare）有前复权，影响收益计算的准确性。

**风险 3：幸存者偏差**

股票池基于**当前**数据库构建，无法回溯已退市/暂停上市的股票。
**真实回测的收益会低于此处的数字。**

### 实盘必须改的两处

1. **加止损或减仓**——回撤 45% 是不可接受的
2. **不要照抄 Top 组**——那是 5,000 只里的前 1,000，你的资金量可以更集中

## 六、必须走量化吗：不必须

这是你问的最重要的问题。**答案是：不必须。**

### 方案 A：完全不用量化（推荐给绝大多数人）

**做法**：每月定投沪深300 ETF（510300），只买不卖。

| 项目 | 数值 |
|---|---|
| 年化成本 | 约 0.1%（佣金万2.5，多数券商有 5 元最低门槛） |
| 换手 | 0 |
| 需要的能力 | 每月固定日期下单 |
| 需要的时间 | 每季度 10 分钟 |

**本项目量化方案的超额是 +0.12pp，扣除操作成本后可能归零。**
而 A 方案的 0.1% 成本几乎为零。

**如果你不能坚持每月操作、也没兴趣理解因子逻辑，A 方案更合理。**

### 方案 B：半量化（推荐的折中）

只用**一个**最简单的规则，不做多因子：

> 每季度末，买入「过去 120 日回撤最深」的前 20 只股票，各 5% 仓位。

理由：`drawdown_60` 的 IC_20 = +0.5014，是全部因子里最强的。
**不需要跑任何回测、不需要 23 个因子、不需要中性化。**

风险：单一因子失效就全失效（本项目已证实 bp 就是这么失效的）。

### 方案 C：完整量化

需要前面全部四节的准备工作。**适合资金量 50 万以上、
且愿意每季度花 1 天重跑检验的人。**

### 我的判断

| 你的情况 | 建议 |
|---|---|
| 资金 < 50 万 | 方案 A。超额 0.12pp 不足以覆盖摩擦成本 |
| 50-200 万 | 方案 B。简单规则 + 严格执行 |
| > 200 万且有量化兴趣 | 方案 C |
| 不想每月操作 | 方案 A，定投 ETF 并设好自动扣款 |

## 八、下一步（如果继续做）

**优先级 1：解决回撤，而不是提高命中率**

−44.84% 的回撤让 +0.12pp 的超额毫无意义。
方向：波动率目标（控制组合波动在年化 15% 以内）、
行业约束（单行业不超过 20%）、个股上限。

**优先级 2：稳健性检验**

当前 `drawdown_60` 只有 2016-2026 一个样本期、一种市场状态。
需要做：分年度检验、剔除 2015 牛市、只看 2018/2022/2024 熊市。

**优先级 3：beta 中性化**

组合的 −44.84% 回撤里有多少是市场 beta？
控制后可能超额会改善，也可能会消失。必须验证。
