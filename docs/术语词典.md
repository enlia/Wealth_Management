## 一、价格结构符号

| 符号 | 英文 | 中文 | 真实例子 |
|---|---|---|---|
| **H** | High | 波段高点 | 中远海能 600026 的 H = **20.57**（2022-09-22） |
| **L** | Low | 波段低点 | 中远海能 600026 的 L = **15.42**（2022-10-13） |
| **HH** | Higher High | 更高的高点 | 宁波银行 002142：H1=28.53 → H2=30.43，H2 > H1 ✅ |
| **HL** | Higher Low | 更高的低点 | 宁波银行 002142：L1=26.82 → L2=28.40，L2 > L1 ✅ |
| **LH** | Lower High | 更低的高点 | 恒瑞医药 600276：65.63 → 58.67 → 55.45 → 54.62 → 47.39 |
| **LL** | Lower Low | 更低的低点 | 恒瑞医药低点同步下移 |

### 核心口诀

```
HH + HL = 上涨趋势（楼梯往上走）
LH + LL = 下降趋势（楼梯往下走）
```

⚠️ **只满足 HL 不满足 HH = 下跌途中的反弹** ← 这是最容易亏钱的形态

**真实案例**：利尔化学 002258
- 1/30 周见顶 **17.85**
- 5/22 周见底 **11.58**
- 7/31 周反弹至 **16.54**、9/11 周 **16.86**（两次越过 0.618 位 15.46）
- **但高点从未突破 17.85** → 属下降趋势反弹 → 9/30 跌回 **13.88**

## 二、支撑与阻力

### 支撑位（Support）

**大白话**：某个价位，价格每次跌到那里就有人接盘、止跌反弹，这个价位就叫支撑位。

**它是一个区域，不是一条精确的线**（如"98~101 元一带"）。

### 四个常见来源

| 来源 | 说明 |
|---|---|
| **前期低点** | 上次跌到这里就反弹了，大家记住位置，这次有人抢着买 |
| **成交密集区** | 大量筹码曾在此换手，跌回来时套牢者补仓、错过者买入 |
| **整数关口** | 10 元、50 元、100 元、3000 点，纯粹是心理习惯 |
| **均线附近** | 60 日线、年线，很多资金按均线操作 |

### 核心认知

> **支撑位不是价格的数学属性，而是"在那个价位当时有人愿意买"这个事实的记录。**

### 为什么会失效

因为**买盘的原因会消失**：

| 阶段 | 现象 |
|---|---|
| ① 有效 | 跌到 100 元就有人买 → 反弹。说明有真实承接力 |
| ② 跌破 | 某次跌到 100 元，买盘不见了 → 直接跌穿（基本面恶化/大盘转弱/资金撤离） |
| ③ 角色反转 | 跌破后原价买入者全被套。价格再反弹到 100 附近时，这批人急着解套卖出 → **支撑变阻力** |

⚠️ **支撑位被测试次数越多，越接近失效**——每次测试都在消耗那里的买盘，"反复测试"本身说明卖压很强。

### 学术证据

**Osler (2000)** 用 6 家交易商**实时公开**的支撑阻力水平做检验（消除了事后偏差），发现订单会在这些价位聚集——**这是唯一机制清晰的技术分析证据**。

⚠️ **但反过来看**：这个机制依赖**机构订单流**。个人参与时，你是在别人的订单聚集区里，**你反而是被收割的一方**。

## 三、斐波那契回撤

### 计算

```
回撤比例 = (H - 当前价) / (H - L)
反弹进度 = (当前价 - L) / (H - L)
```

**回撤位**（从 L 往上）：
| 档位 | 公式 |
|---|---|
| 0.236 | L + (H−L)×0.236 |
| 0.382 | L + (H−L)×0.382 |
| 0.500 | L + (H−L)×0.500 |
| **0.618** | L + (H−L)×0.618 |
| 0.786 | L + (H−L)×0.786 |

### 0.618 的来源

`0.618 = (√5 − 1) / 2`，即**黄金比例的倒数**。确实广泛存在于自然界与美学中。

### ⚠️ 关键：它不是支撑位

本工作区的实证结论（1,273 个样本）：

| 检验标准 | 真支撑位应该 | 0.618 位的实测 |
|---|---|---|
| 价格到这里会受阻吗 | 会停 | ❌ 81 个失效案例 **100% 都越过了它**才掉头 |
| 到这里买入能赚钱吗 | 正收益 | ❌ 收益中位数 **−3.68%**，胜率 41.8% |
| 相邻位置有区别吗 | 明显特殊 | ❌ 与 0.5、0.382 档成功率**完全相同（93.6%）** |

**两者的本质区别**：
- **前期低点**是真实成交出来的价格 → 有**市场记忆**
- **0.618** 是你自己算的一个数 → 那儿**本来什么都没有**

### 学术结论（2026-10 调研）

**已被严格检验为不支持**（ESWA 2022，logistic 回归，样本外）：
- 道指/纳指/DAX 三个市场的斐波那契比率斜率**全部不显著**
- 跑输**随机**选择的非斐波那契基准
- 跑输**买入持有指数**

需区分两个命题：
- 「斐波那契比率有数学美感」✅ 成立
- 「市场在该百分比更易反转」❌ **未被证据支持**

### 正确用法（降级使用）

| 用途 | 是否可行 |
|---|---|
| 描述工具：告诉你"回调到了什么程度" | ✅ 客观事实 |
| 风险参考：跌破 0.618 = 反弹力度衰竭 | ✅ 可作止损触发条件之一 |
| 共同语言 | ✅ 短期可能因集体行为产生反应 |
| **预测工具 / 支撑位买入依据** | ❌ **不能** |

## 四、趋势

### 道氏趋势判定

**上涨趋势**：后一个高点高于前一个高点 **且** 后一个低点高于前一个低点（**HH + HL 双条件**）

只满足一条的常见情况是「**下降趋势中的反弹**」（低点抬升但高点未创新高）。

### 趋势的三层时间尺度

| 层级 | 时间跨度 | 依据 |
|---|---|---|
| **主要趋势** | 1 年以上 | 基本面、周期 |
| **次级趋势** | 3 周 ~ 数月 | 技术形态的主要研究对象 |
| **短暂趋势** | 3 周以内 | 噪声为主 |

### 趋势破坏的判定

**收盘价跌破前一个关键低点**。

### ⚠️ 趋势是事后确认的

这是最重要的认知：**你现在看到的"上涨趋势"是事后贴标签，事前无法知道**。

- 趋势成立 ≠ 立刻上涨
- 等你确认趋势时，往往已经涨了一段
- 这就是为什么"追高"和"抄底"都有风险

### 辅助验证（非充分条件）

- 均线多头排列（MA5 > MA20 > MA60）
- MACD 在零轴上方
- 量价配合：**上涨放量、回调缩量**

## 五、期望值与风险（最核心的一组概念）

### 公式

```
期望值 = 胜率 × 平均盈利 − 败率 × 平均亏损
```

### ⚠️ 常见误解：高胜率 = 赚钱

| 策略 | 胜率 | 平均盈利 | 平均亏损 | 期望值 |
|---|---|---|---|---|
| A | 70% | +1% | −3% | **−0.2%（负期望）** |
| B | 35% | +4% | −1.5% | **+0.425%（正期望）** |

**策略 A 就是散户的典型结构**：赚一点就跑（处置效应）、亏了死扛（损失厌恶）。
**策略 B 是趋势跟踪的结构**：频繁小亏，偶尔大赚。

**学术支撑**：Moskowitz, Ooi & Pedersen (2012) 用 58 个期货品种 1965-2009 数据证明时间序列动量有效——而趋势跟踪的胜率只有 **30%~40%**。

### 算术期望 vs 几何期望（最危险的陷阱）

**每期全仓押注**，胜率 50%、赚 50% / 亏 40%：
- 算术期望 = 0.5×50% + 0.5×(−40%) = **+5%**（看起来是赚钱的）
- **但几何增长率是负的**，资金曲线一路向下

原因：赚 50% 后亏 40% 剩 90%，**+50% 的逆运算是 −33.3% 而不是 −50%**。

**这就是"控制亏损幅度"比"追求盈利幅度"重要得多的数学根源。**

### 赌徒破产公式（赔率 1:1 时）

```
破产概率 = ((1−p)/p)^初始资本单位数
```

⚠️ **当胜率正好 50%（零优势）时，无论本金多少，长期破产概率都是 100%**——这就是赌徒必败定理。

**样本量门槛**：假设策略真实胜率 55%，要以 95% 置信度证明它不是运气：

```
n > (1.96 / 0.05)² × 0.55 × 0.45 ≈ 380 笔
```

**少于 380 笔交易记录，你根本无法判断自己有没有优势。**

## 六、仓位与凯利公式

### 1~2% 法则

永远用「我能亏多少」倒推「买多少」：

```
仓位 = (总资金 × 1%) ÷ (买入价 − 止损价)
```

**算例**：10 万本金，单笔最多亏 1000 元。买入价 10 元、止损 9.5 元（每股亏 0.5 元）
→ 仓位 = 1000 ÷ 0.5 = **2,000 股 = 2 万元**（占总资金 20%）
→ 若止损放宽到 9 元（每股亏 1 元），仓位必须砍到 1,000 股

**止损越宽，仓位越轻**——这是铁律。

### 凯利公式

```
f* = (p×b − q) / b
```
其中 p = 胜率，b = 盈亏比，q = 1−p

**实盘用分数凯利（半凯利）**，因为参数估计有误差，而超押的代价是几何级的。

### ⚠️ 凯利的前提常被误解

Kelly 公式假设**独立重复赌局**，而**股票收益恰恰不是 IID 的**。

**LTCM 案例**：首年赚 16 亿美元，两年后崩塌——正是把非 IID 收益当独立试验下注的结果。

### 本机实测的最低本金要求

A 股最小 100 股（科创板 200 股）。按 1% 法则反推：

| 标的 | 买入价 | 止损价 | 股数 | **所需最低本金** |
|---|---|---|---|---|
| 药明康德 603259 | 167.34 | 149.70 | 100 | **176,400 元** |
| 美迪西 688202 | 107.64 | 87.40 | 200 | **404,800 元** |

**10 万本金硬买药明康德一手，单笔风险就是 1.76%，超了纪律近一倍却毫无察觉。**

## 七、交易行为术语

| 术语 | 定义 | 学术依据 |
|---|---|---|
| **处置效应** | 赚了一点就急着卖，亏了却死扛 | Barber & Odean (2000) |
| **损失厌恶** | 亏损带来的痛苦大于同等收益的快乐 | Kahneman & Tversky (1979) |
| **锚定效应** | 死盯着买入价当参照 | — |
| **羊群行为** | 跟着别人买 | — |
| **过度自信** | 连续盈利后高估能力（"最近连赚5次，这次也稳"） | Barber & Odean |
| **赌徒谬误** | "已经跌这么多了，该反弹了" | — |

### 涨跌幅不对称（必须理解）

| 事件 | 数学 | 需要涨回 |
|---|---|---|
| 赚 +50% 后亏 −50% | 剩 75% | +33.3% |
| 亏 −50% 后赚 +50% | 剩 75% | +33.3% |
| 亏 −72.81%（上证 2007→2008） | 剩 27.19% | **+267.85%** |

**上证指数 6124.04 → 1664.93 = −72.81%，回本需要 +267.85%。19 年过去（2026-09-30），指数 3842.19，仍差 59.4%。**

## 八、其他关键术语

| 术语 | 含义 |
|---|---|
| **HH/HL/LH/LL** | 见第一节 |
| **回撤（Drawdown）** | 净值从高点的跌幅 |
| **Calmar Ratio** | 年化收益 / 最大回撤 |
| **Sharpe Ratio** | 超额收益 / 波动率 |
| **IC / ICIR** | 因子预测力 / 预测力的稳定性 |
| **前视偏差** | 回测中用了当时不可得的信息 |
| **幸存者偏差** | 用当前名单回测历史 |
| **过拟合** | 参数调到刚好拟合历史 |
| **数据窥探（data snooping）** | 试了足够多的组合，总有一个"显著" |
| **复权/前复权** | 消除除权除息造成的跳空 |
| **不复权** | 通达信本地 .day 的默认形态 |
| **滑点** | 实际成交价与信号价的差 |
| **成交量 vs 成交额** | 通达信 .day 中：vol=股，amount=元 |
