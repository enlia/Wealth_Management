# 因子有效性检验方法论

> 本方法论来自本工作区已完成的**黄金分割实证研究**（1,273 个样本），是本工作区的核心研究模板
> 整理时间：2026-10-02

---

## 一、为什么必须先做"检验"而不是"建模"

90% 的人做量化第一个项目是"用 LSTM 预测股价"，然后失败。原因不是模型不好，而是**跳过了证伪环节**——你还没学会"怎么证明一个想法是错的"，就无法知道"证明它是对的"有没有意义。

**正确的顺序**：

```
提出假设 → 构造样本 → 设对照组 → 统计检验 → 承认无效
                    ↓
              （有效才继续）→ 组合成策略 → 回测 → 小仓位实盘
```

**核心认知**：一个方法"看起来有效"和"统计上可靠"是两件事。绝大多数技术指标的"有效"都属于前者。

## 二、六个步骤（可直接套用的模板）

### 步骤 1：明确假设，写成可证伪的陈述

❌ 不好："均线多头排列有效"
❌ 不好："黄金分割有预测力"
✅ 好："**在双周期上涨趋势前提下，价格触及 0.618 回撤位后，未来 40 个交易日的收益中位数显著低于无条件基准**"

**关键**：假设必须能算出具体数字，且能算出"如果无效会是多少"。

### 步骤 2：构造样本（这一步最容易埋前视偏差）

**前视偏差（Look-ahead Bias）**：在回测中使用了当时还不可得的信息。

**实战案例（本工作区已犯过）**：
- 摆动低点 L 需要未来 12 根 K 线才能确认
- 修正前从 L 的**次日**开始观察 → 成功率虚高 **95.9%**
- 修正后从 **L 确认之后**开始观察 → 成功率 **93.6%**
- **教训**：真实交易中你做不到"提前知道低点"

**检查清单**：
- [ ] 信号的确认时点是否用了未来数据？
- [ ] 财务数据的报告期与披露日是否混淆？（2026 中报数据在 8 月底才披露）
- [ ] 复权因子是用当日的还是后来的？
- [ ] 板块成分股名单是否是"当前快照"冒充历史？（**幸存者偏差**）

### 步骤 3：设对照组（不做这一步，结论毫无意义）

**为什么必须**：能涨到 0.618 的反弹本身就更强势。你若只看"触及 0.618 的样本后来涨了多少"，得到的是**选择偏差**，不是预测力。

**三种对照设计**：

| 对照类型 | 做法 | 用途 |
|---|---|---|
| **无条件基准** | 全部样本的收益分布 | 最低标准 |
| **时点正确的条件概率** | 只在"尚未突破前高时"记录事件，再统计后续能否突破 | 避免同义反复 |
| **安慰剂检验** | 随机打乱标签重跑 1000 次 | 排除巧合 |

**同义反复的陷阱（本工作区踩过）**：
如果定义"在**已触及 0.618**的样本内"统计各档位成功率，那么 0.382 / 0.500 / 0.618 三个档位**必然完全相同**——因为能到 0.618 的必然已过 0.5 和 0.382，三者在同一集合内就是同一个东西。实测结果正是如此：**成功率全部 93.6%，增量为 0**。

### 步骤 4：统计检验

| 检验 | 用途 | 判据 |
|---|---|---|
| **t 检验** | 收益均值是否为 0 | p < 0.05 |
| **IC / ICIR** | 因子预测力 | IC 均值、ICIR > 0.3 |
| **分组单调性** | 分 5 组看收益是否单调 | Spearman 秩相关显著 |
| **Newey-West** | 收益自相关修正 | 序列相关时必须用 |
| **Bootstrap** | 小样本稳健性 | 重采样 1000 次 |

**多空组合是核心指标**：如果"最高组 − 最低组"的收益不显著为正，单因子就没有实用价值。

### 步骤 5：子区间稳定性检验（最容易被忽略，也最重要）

**把样本期切成 3~4 段，分别检验。**

如果因子只在某一段有效（比如 2015-2018），在其他段无效，那么：
- 你无法判断自己是在"发现 alpha"还是"拟合历史"
- **几乎所有过拟合的因子都能通过全样本检验**

黄金分割研究中的做法：报告期 2021-08 ~ 2026-02，4.5 年，分段检验。

### 步骤 6：成本敏感性检验

**这一步决定"实盘能不能赚钱"**，很多研究在这一步就死了。

```
年换手倍数 × 双边成本 = 年成本
```

| 策略换手 | 年单边换手 | 年成本（双边 0.15%） | 需要毛收益 |
|---|---|---|---|
| 波段（持仓 1 月） | 12 | 3.6% | > 3.6% |
| 中频（持仓 1 周） | 50 | 15.0% | > 15% |
| 日频 | 125 | **37.5%** | > 37.5% |

**日频策略在散户费率下是数学上不可能盈利的。**

**必须检验**：扣除成本后，多空组合是否仍显著为正？

## 三、本工作区的实证案例：黄金分割

**完整的六步示范**（详见 `05_实证研究/`）：

| 步骤 | 做法 | 结果 |
|---|---|---|
| 1. 假设 | 0.618 回撤位有预测力 | — |
| 2. 样本 | 全市场 9,570 标的，双周期 HH/HL + 回调 ≥10%，得 **1,273 个**有效波段 | 已修正前视偏差 |
| 3. 对照 | 统计"已触及 0.618"的子集内各档位成功率 | **0.382 / 0.500 / 0.618 全部 93.6%，增量 0** |
| 4. 统计 | 0.618 档买入持 40 日 | 收益中位数 **−3.68%**，胜率 **41.8%** |
| 5. 子区间 | 81 个失效案例的反弹进度 | **中位数 82.4%**，最小 62.2%，最大 99.8%——**100% 都越过 0.618 才掉头** |
| 6. 成本 | 四档全部负收益 | 越接近前高越差 |

**结论**：0.618 **不是支撑也不是阻力**，只是路径上的一个刻度。**决定成败的是"能否创新高"（HH），不是"到没到 0.618"**。

**方法论价值 > 结论价值**：这套流程可以直接套用到任何技术指标上。

## 四、五个必避的坑

| 坑 | 表现 | 后果 |
|---|---|---|
| **前视偏差** | 用未来才确认的信号 | 成功率虚高（实测 95.9% → 93.6%） |
| **幸存者偏差** | 用当前成分股名单回测历史 | 收益系统性高估 |
| **过拟合** | 100 个零期望策略测 50 笔，最好的落在 +2.5σ | 看起来完美，真实期望是 0 |
| **多重比较** | 斐波那契有 5 档，价格必然触及某一档 | "命中"不构成证据 |
| **忽略成本** | 只算毛收益 | 实盘直接亏 |

## 五、必读的参考文献

| 文献 | 价值 |
|---|---|
| **Grinold & Kahn, "Active Portfolio Management"** | 基本法则 `IR = IC × √BR`——量化从业者的必读书 |
| **Moskowitz, Ooi & Pedersen (2012), "Time Series Momentum"** | 58 个期货品种 1965-2009，趋势跟踪的学术基准 |
| **Brock, Lakonishok & LeBaron (1992)** | 技术规则统计显著性检验的经典（及其争议） |
| **Bajgrowicz & Scaillet (2012), "Technical trading revisited"** | 指出扣除成本后超额收益大幅衰减 |
| **Fama & French (1992/1993)** | 因子模型的源头 |
| **Loughran & McDonald (2011)** | 文本情绪因子（用于 A 股公告/研报） |

**结论性提示**：动量、价值、规模、低波动四大因子有大量学术支撑；而**斐波那契回撤、MACD、KDJ 这类技术指标缺乏独立的大样本实证文献**——不是已被证伪，而是**未被验证**。

## 六、检查清单（每个因子研究都过一遍）

- [ ] 假设是否可证伪？是否写成具体数字？
- [ ] 样本构造是否含前视偏差？
- [ ] 是否设置了真正的对照组？
- [ ] 是否做了统计检验（不只是看图）？
- [ ] 是否做了子区间稳定性检验？
- [ ] 扣除交易成本后是否仍有效？
- [ ] 是否检查了多重比较问题？
- [ ] 失效案例是否分析了**失效方式**（而不只是失效比例）？
- [ ] 是否有 100+ 笔的样本量（少于 380 笔无法证明胜率优势）？
