## 二、行情文件格式

### 2.1 日线 `.day`（32 字节定长）

**二进制布局（小端）**：

| 偏移 | 字段 | 类型 | 含义 |
|---|---|---|---|
| 0 | date | uint32 | YYYYMMDD，如 20151125 |
| 4 | open | uint32 | 开盘价 × 100 |
| 8 | high | uint32 | 最高价 × 100 |
| 12 | low | uint32 | 最低价 × 100 |
| 16 | close | uint32 | 收盘价 × 100 |
| 20 | amount | **float32** | 成交额（元） |
| 24 | vol | uint32 | 成交量（股） |
| 28 | — | uint32 | 保留 |

**numpy 解析定义**（最快写法）：
```python
DTYPE = np.dtype([
    ("date","<u4"), ("open","<u4"), ("high","<u4"),
    ("low","<u4"), ("close","<u4"), ("amount","<f4"),
    ("vol","<u4"), ("rsv","<u4"),
])   # itemsize == 32
raw = np.fromfile(path, dtype=DTYPE)
```

**验证样本**：`sh600519.day` 前 32 字节
```
a1 7b 33 01 34 53 00 00 93 53 00 00 6c 52 00 00
84 53 00 00 7d 29 bf 4d 0a ce 1c 00 00 00 01 00
```
解码 → 2015-11-25，OHLC = 212.36 / 213.95 / 210.84 / **213.80**，成交量 1,899,018 股 ✅

**⚠️ 重要：不复权原始价。**

### 2.2 分钟线 `.lc1` / `.lc5`（同样是 32 字节，但字段解释不同）

**这是本轮逆向验证的新发现**：

| 偏移 | 字段 | 类型 | 含义 |
|---|---|---|---|
| 0 | date | **uint16** | 日期偏移（相对通达信内部基准） |
| 2 | time | **uint16** | 距 00:00 的**分钟数**（571 = 9:31） |
| 4 | open | **float32** | 开盘价（**不复权原值**） |
| 8 | high | float32 | 最高价 |
| 12 | low | float32 | 最低价 |
| 16 | close | float32 | 收盘价 |
| 20 | amount | float32 | 成交额（元） |
| 24 | vol | uint32 | 成交量（股） |
| 28 | — | uint32 | 保留 |

**验证样本**：`sh600519.lc1` 前 32 字节
```
d4 b2 3b 02 00 20 a3 44 b8 a6 a3 44 b8 86 a2 44
00 e0 a2 44 c5 5e 82 4d c0 32 03 00 00 00 00 00
```
解码 → `b2d4`=45780(日期偏移)，`023b`=571 分钟 = **9:31**，
OHLC = 1315.125 / 1315.36 / 1314.35 / **1314.5**，
成交额 1.6 亿，成交 209,600 手 ✅

**⚠️ 与日线的三个关键差异**：
1. 时间戳是 **uint16**（日线是 uint32）
2. 价格为 **float32**（日线是 uint32×100）
3. 成交量单位是**手**（日线是股）

**⚠️ 陷阱**：`lc1` 存的是**不复权**价。跨除权日直接画图会跳空，指标全部失真。

## 三、T0002/hq_cache 内部数据库 ★★★

**这是本工作区最有价值的发现**——通达信不只存行情，还有可解析的数据库。

### 3.1 `base.dbf`（3.7 MB）——全市场财务快照

- **格式**：dBase III，7,992 条记录 × 40 字段，记录长 481 字节
- **头结构**：offset 4-7=记录数(uint32 LE)、8-9=头长度、10-11=记录长度
- **字段描述**：offset 32 起，每 32 字节（0-10 字段名 GBK、11 类型、16 长度、17 小数位），以 `0x0D` 结束

### 3.2 `infoharbor_block.dat`（724 KB）——板块定义与成分股

## 四、质量校验方法（可复用）

**交叉验证是发现数据错误最有效的手段。**

方法：用两个独立数据源算同一个量，看差异。

本机验证实例：
```
行情：贵州茅台 总市值 15,733.78 亿，PB = 6.26
  → 反推净资产 = 15733.78 / 6.26 = 2,513 亿
dbf：茅台净资产 = 2512.5 亿
  → 差异 = 0.13%  ✅
```

**这个检验抓出了 10 倍单位错误**：
- 错按万元换算 → 中位差 **90.00%**，±5% 内占比 0.0%
- 改成千元 → 中位差 **0.13%**，±5% 内占比 57.7%

**建议**：每次引入新数据源，都做一次交叉验证再使用。

## 五、常见陷阱汇总

| 陷阱 | 表现 | 解决 |
|---|---|---|
| 代码相同、市场不同 | `sh000001`=上证指数，`sz000001`=平安银行 | **按文件所在目录决定前缀**，不能按代码首位 |
| 88 开头误判 | 880xxx 是通达信板块指数，存在 **sh** 目录 | `market_of` 加特判 |
| 分钟线扩展名 | 不是 `.day`，是 `.lc1`/`.lc5` | 用 `*.day` glob 会得到 0 |
| 周线日期错位 | `resample('W-FRI')` 会把 9/30(周三) 标成 10-02 | 用组内**最后一个实际交易日** |
| 财务单位 | 千元 / 万股 / 元 混用 | 用 PB 反推净资产做交叉验证 |
| 不复权 | 跨除权日跳空，指标失真 | 前复权需外部接口 |
| 名称不落盘 | 通达信名称在客户端内存里 | 从腾讯接口抓名称表 |

## 六、怎么用（推荐顺序）

```bash
# 1. 查看数据概况
python tdx.py info

# 2. 看个股 K 线
python tdx.py show 603259 --period weekly --last 8
python tdx.py ind 002142                    # 技术指标

# 3. 导出 CSV
python tdx.py export 002142

# 4. 全市场批量导出
python tdx.py export-all --workers 8
```

或直接用 SQLite 查询（见 `02_数据库/schema.sql`）：
```sql
SELECT code, date, high, low FROM bar_weekly
WHERE code='sh603259' ORDER BY date DESC LIMIT 8;
```
