# Tushare Pro 积分机制完全指南

> 信息来源：Tushare Pro 官方权限页（https://tushare.pro/document/1?doc_id=290）
> 整理时间：2026-10-03

## 一、先纠正一个常见误解

**⚠️ 分钟线不在积分体系内。**

官方原文：
> "分钟和港美股数据权限**不在积分范畴内**，各类分钟单独分别开权限，**且不加积分**。"

**即使买到 15,000 积分（1,500 元），也拿不到历史分钟线**——那需要**单独购买 2,000 元/年**。

这一点很多网上文章讲错（包括我自己此前也说"5000 积分可拿分钟线"），务必注意。

---

## 二、两套并行的权限制度

| 制度 | 覆盖范围 | 获取方式 |
|---|---|---|
| **积分权限** | A股常规数据：日/周/月线、财务、基础信息、指数成分、复权因子 | 积分或购买（1 元 = 10 积分） |
| **独立权限** | **历史分钟、实时分钟、港美股、期权、新闻、公告、研报、政策法规、集合竞价** | **单独按年付费，不加积分** |

## 四、2000 积分到底能干什么（核心问题）

### ✅ 能拿到（200 元档位）

| 类别 | 主要接口 |
|---|---|
| **行情** | `daily`（日线，**含复权**）、`weekly`、`monthly` |
| **复权** | `adj_factor`（复权因子） |
| **财务** | `income`（利润表）、`balancesheet`（资产负债表）、`cashflow`（现金流量表）、`fina_indicator`（财务指标） |
| **基础信息** | `stock_basic`（股票列表）、`trade_cal`（交易日历） |
| **指数** | `index_basic`、`index_daily`、`index_weight`（指数成分权重） |
| **行情衍生** | `daily_basic`（每日指标：PE/PB/市值/换手率）、`limit_list_d`（涨跌停） |
| **板块** | 概念板块、申万行业分类及成分 |
| **其他** | 龙虎榜、融资融券、大宗交易、股东人数等（以各接口文档标注的积分数为准） |

### ❌ 拿不到（必须单独付费）

| 数据 | 单独价格 |
|---|---|
| **历史分钟线**（1/5/15/30/60min，2009 年起） | **2,000 元/年** |
| 期货 / 期权 / 申万分钟 | 各 2,000 元/年 |
| **实时分钟** | 1,000 元/**月**（约 1.2 万/年） |
| 港股财报 500 / 美股日线 2,000 / 美股财报 500 | 500~2,000 元/年 |
| 新闻资讯 1,000 / 公告信息 1,000 | 各 1,000 元/年 |
| 券商研报库 500 / 集合竞价 500 / 政策法规库 1,000 | 500~1,000 元/年 |
| 特色数据（盈利预测、筹码分布、胜率、券商金股） | 需 10,000 积分（1,000 元） |

## 五、200 积分够不够？—— 对你的判断

### 结论：**200 元是唯一"闭眼买"的支出，2000 积分对你的用途足够**

**理由**：

**① 你最缺的三样，2000 积分全都有**
| 你的缺口 | 2000 积分能否解决 |
|---|---|
| 历史财务三表（多期序列） | ✅ `income` / `balancesheet` / `cashflow` |
| 复权因子 | ✅ `adj_factor` |
| 财务指标（ROE 连续性、扣非净利润） | ✅ `fina_indicator` |

**② 免费渠道的实测对比**

| 你已经免费拿到的 | 免费源的局限 |
|---|---|
| 本机通达信 16,456,556 条日线（10.5 年） | ✅ 已经很完整，Tushare 补不上更多 |
| 547 个板块 + 79,455 条成分股 | ✅ 够用 |
| 财务快照 7,992 条（单期） | ❌ **单期，无法算同比** |
| 复权因子 286/300 只（免费源） | 🟡 覆盖不全 |
| 申万行业 31/131/335 个（免费源） | ✅ 够用 |
| 指数成分 11 个（免费源，**仅 2 期快照**） | ⚠️ **有幸存者偏差** |

**③ 免费源的限流是真问题**

本次实测（agent 报告）：新浪源连续请求约 **3,000 只后触发封锁**，封锁窗口 10~30 分钟，稳定吞吐仅 **0.6~1.1 只/秒**。这导致财务数据只覆盖到 2,470/6,140 只（40%），资产负债表只有 83 只。

**Tushare 的 2000 积分是 200 次/分钟、10 万次/天/接口** —— 相当于免费源吞吐的 **20~200 倍**，且有 SLA，不会随时挂。

**④ 200 元相对于你的处境**

- 占你可能亏损金额的极小比例（一次错误交易可能就亏这个数）
- 但换来的是**能算出"净利润同比""ROE 连续性""扣非净利润"**的能力
- 这三项是价值投资与基本面因子的**命门**

### ⚠️ 但要注意：2000 积分买不到分钟线

如果你需要分钟线，得**另外付 2,000 元/年**。

**我的建议**：先用 200 元买 2,000 积分解决财务数据，**分钟线用 QMT 免费拿**（开 10 万券商账户，客户端自带数据下载）。这样总支出仍是 200 元。

## 六、怎么获取积分（省钱的路子）

| 方式 | 说明 |
|---|---|
| **日常购买** | 1 元 = 10 积分，200 元 = 2,000 积分 |

**⭐ 最省的路径**：先进微信专业用户群拿 5,000 积分（免费），如果 5,000 积分不够再买。

⚠️ **注意**：官方明确写了"**购买前请确认是否真的需要**"，且**不支持退款**。

## 七、给你的最终建议

```
第 1 步（0 元）：注册 Tushare，加入微信专业用户群 → 拿 5,000 积分
                 → 5,000 积分 = 500 元档位，频次 500 次/分、常规数据无上限
第 2 步：验证 5,000 积分是否够用
         - 财务三表、fina_indicator、复权因子、指数成分、每日指标 → 应该都够
         - 逐个接口查 document/2 看标注的积分要求
第 3 步：若不够，再买 2,000~5,000 积分补到所需档位
第 4 步：分钟线 → 走 QMT（免费，需券商 10 万门槛），不要花 2,000 元/年
```

**为什么推荐先拿 5,000 而不是直接买 2,000**：
- 5,000 积分档位是"**常规数据无上限**"，2,000 档位每个 API 有 10 万次/天限制
- 如果你要做全市场 6,000 只 × 10 年的财务数据拉取，10 万次/天会很快触顶
- **但 5,000 积分仍拿不到分钟线和特色数据** —— 那些是 10,000 分和独立权限的事
