## 六、风险提示

⚠️ **TusharePro 2026 年突发停运**，量化圈震动。教训：

1. **不要把数据源单点依赖** —— 至少准备 2 个可替换源
2. **落到本地才算数** —— 云端接口随时可能消失，本地 SQLite/Parquet 才是你的
3. **关注服务可持续性** —— 数据源的商业模式、服务器成本、合规风险都会影响可用性

**推荐架构**（多源冗余）：
```
主源：Tushare / 券商接口
   ↓ 每日同步
本地库：SQLite（查询）+ Parquet（归档）
   ↓
冗余源：baostock / akshare（自动补缺）
```
