# 数据来源全景：本机通达信数据的能力与边界（2026-10-05）

> **回答三个问题**：平常人做量化数据从哪来？通达信权威吗？现在的数据是什么组成？

---

## 一、平常人做量化，数据从哪来

按获取难度和成本，分四档：

| 档次 | 数据源 | 典型代表 | 成本 | 能做什么 |
|---|---|---|---|---|
| **免费·官方** | 交易所公开 | 上交所/深交所官网、证监会 | 0 | 年报、公告、指数成分 |
| **免费·第三方** | 财经网站接口 | **AkShare**（爬东财/新浪等）、**通达信客户端** | 0 | 日线、财报、板块 |
| **付费·数据服务** | 专业数据商 | **Tushare Pro**、Wind、聚宽、米筐 | 1元~万元/年 | 全字段、PIT 数据、退市股 |
| **付费·专业** | 交易所直采/彭博 | 上交所 Level-2、彭博终端、Bloomberg | 万元~/年 | 逐笔成交、盘口 |

**普通投资者的现实路径**：
1. **AkShare 免费起步** —— 本项目的财务数据就是这么来的
2. **通达信客户端导数据** —— 本项目 16.4M 条日线就是这么来的（逆向 `.day` 二进制格式）
3. **Tushare Pro 补关键字段** —— 1 元 = 10 积分，可换复权因子与退市股

**为什么不能只用一个源**：
- AkShare 稳定但慢，且接口常需代理
- 通达信免费但缺复权/退市股/PIT 财务
- Tushare 补关键字段但年费逐年上涨

## 二、通达信数据权威吗？

**一句话：行情（价格/成交量）权威且足够，但不适合做量化研究。**

### 权威的部分 ✅

| 项目 | 评价 |
|---|---|
| 行情来源 | 直连交易所，Level-1 授权数据，与券商看盘一致 |
| 价格序列 | 16,456,556 条日线，覆盖 2015-12 至 2026-10 |
| 覆盖度 | 9,595 个标的（含 5,593 只 A 股），逐年递增 3,630 → 9,592 |
| 板块/概念 | 547 个板块、529 个标签，**这是通达信的相对优势** |
| 指数成分 | 含 ZS_沪深300 / ZS_中证500 等，可直接取 |

**价格数据的可靠度**：
- 96.6% 的日波动在 ±5% 以内（正常）
- 茅台、平安银行等连续价格无异常
- 品种过滤有效（`is_a_share` 正确排除了 4,002 个 ETF/指数）

### 不权威的部分 ❌

| 问题 | 实测 | 后果 |
|---|---|---|
| **复权处理** | 主板污染率 0.291%，平安银行 2016-06-16 单日 −17.91% 明显是除权跳空 | **年化偏差 2.3pp** |
| **没有复权因子字段** | 表结构里只有 OHLCV，无 adj_factor | 无法自行修正 |
| **PE/PB 是静态快照** | `stock_info.pe` 是「当前」值，不是历史逐日 | 用它做因子会前视偏差 |
| **换手率同样静态** | 同上 | 同上 |
| **行业字段缺 37%** | 6,082 只完全无行业值 | 行业中性化基本失效 |
| **无退市股** | 含「退/ST」的仅 16 只 | **幸存者偏差，收益被高估** |
| **无涨跌停价、无停牌标记** | — | 无法建模「涨停买不到」 |

**关键判断**：通达信是**给散户看盘的工具**，不是量化数据库。
它假设「你不会做严肃的历史统计」，所以不提供复权因子、PIT 财务、退市股。

### 能力矩阵

**✅ 有且质量可用**：
- 日线 OHLCV + 成交额（16.4M 行）
- 周线（3.5M 行）
- 概念板块 529 个标签 / 547 个板块
- 指数成分（ZS_ 系列）
- 基础财务 7 字段

**❌ 没有**（按重要性排序）：

| 缺失项 | 影响 | 能否免费补 |
|---|---|---|
| **复权因子** | 年化 2.3pp 偏差 | ❌ 需 Tushare 或自己算 |
| **行业分类**（37% 缺） | 行业中性化失效 | ✅ **本机 boards 字段可补** |
| **退市股票** | 幸存者偏差 | ❌ 需 Tushare |
| **涨跌停价 / 停牌标记** | 无法建模不可成交 | ❌ 需 Tushare |
| **历史 PE/PB（逐日）** | 无法做估值时序因子 | ⚠️ 可用「价格/最新EPS」近似 |
| **十大股东 / 股东户数（历史）** | 缺一类重要因子 | ❌ 需 Tushare |
| **分析师预期** | 缺一类重要因子 | ❌ 需 Tushare 高积分 |
| **完整财报** | 缺资产负债率/商誉/应收等 | ⚠️ AkShare 可免费抓 |
| **分钟数据** | 日内策略不可行 | ❌ 需付费 |

**⚠️ 有一类"看起来有其实没用"的数据**：
`boards` 字段里有 `FG_基金重仓`、`FG_北上重仓`、`FG_股东户数增加`、
`FG_龙虎榜` 等标签，但**每类恰好只存 Top 200 只**（实测验证），
覆盖率仅 3.9%，且是当前快照无历史版本。
→ **横向信息量极低 + 严重前视偏差，不能当因子用。**

## 四、结论

### 通达信够用吗？

**做「验证已有想法」够了，做「系统化研究」不够。**

| 目标 | 通达信够吗 |
|---|---|
| 检验「低波动因子是否有效」 | ✅ 够（价格数据可靠） |
| 检验「价值 + 盈利质量组合」 | ⚠️ 勉强（复权偏差 2.3pp，需先清洗） |
| 系统化挖掘新因子 | ❌ 不够（无复权、无退市股、行业缺 37%） |
| 多因子体系化研究 | ❌ 不够（缺 PIT 财务、缺多类重要因子） |

### 建议的补法

**第一步（免费，立刻做）**：
1. 用 `boards` 字段的板块标签补全行业分类 → 恢复行业中性化
2. 用 `audit_data_quality.py` 清洗除权跳空 → 修正 2.3pp 偏差

**第二步（1 元起，建议）**：
- **Tushare Pro 10 积分**（约 1 元）可换：
  - `pro_bar(adj='hfq')` 复权日线 → 彻底解决复权问题
  - `stock_basic(list_status='D')` 退市股 → 消除幸存者偏差
  - `f_ann_date` 真实披露日 → 消除财务推算误差

**第三步（万元级，个人不建议）**：
- Wind / 聚宽 / 米筐等，或交易所 Level-2

## 五、一句话总结

**通达信的「行情」权威可用，「量化所需的数据」严重不足。**
本项目 16.4M 条日线足以验证单个因子，但缺复权因子、退市股、
行业分类、PIT 财务这四样，限制了它只能做「粗粒度验证」而非「体系化研究」。

**最经济的补法**：用本机 `boards` 补行业（免费）+ Tushare 10 积分补复权（1 元），
合计成本约 1 元，能解决 90% 的数据缺陷。
